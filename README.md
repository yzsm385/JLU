# JLU

吉林大学 **软件学院** 课程笔记与复习资料合集。

这个仓库按课程组织，每门课一个目录，根目录只做索引。笔记以 [Obsidian](https://obsidian.md) 格式编写，直接用 Obsidian 打开对应课程目录即可获得双链、标签与图谱；不用 Obsidian 也能当作普通 Markdown 阅读。

## 课程索引

| 离散数学 | 2026 秋 | [`离散数学/`](离散数学/) | 古典代数（集合论、数论、图论）+ 抽象代数（群论） |

> 后续课程会陆续补充到这里。

## 目录约定

```
JLU/
├── README.md          # 本文件，课程索引
└── <课程名>/          # 一门课一个目录
    ├── README.md      # 课程说明、目录结构、使用方式
    ├── 笔记/          # 章节笔记（Obsidian 双链）
    ├── 复习/          # 复习计划、错题本、速记、模拟卷
    └── 教材/          # 教材与参考书
```

## 关于内容

- 笔记、错题本、速记页、模拟卷、脑图均为**自己整理**，欢迎参考。
- 教材 PDF 仅作个人学习存档，版权归原作者与出版社所有，请勿用于商业用途。
- **课件（老师制作的 PPT / PDF）与作业卷不在本仓库中**，仅在本地保存，以尊重任课教师的劳动成果。
- 仓库中已去除个人隐私信息（姓名、学号、成绩记录等）。
