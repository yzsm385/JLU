# 离散数学

吉林大学软件学院《离散数学》课程笔记与复习资料。

课程分两部分：**离散数学 I（古典代数）** 讲集合论、数论、图论；**离散数学 II（抽象代数）** 讲群、环、域与格、布尔代数。两部分教材同为《离散数学结构（第 2 版）》（欧阳丹彤、杨凤杰、李占山、张永刚，高等教育出版社）。

## 怎么用

**用 Obsidian 打开** `离散数学/` 目录，笔记之间的 `[[双链]]` 可以直接跳转，标签与关系图谱也能正常工作。建议从 `II 抽象代数（群论）/笔记/00 索引.md` 开始，它是整个课程的地图。

**不用 Obsidian** 也没关系，`[[链接]]` 只是纯文本，按文件名在目录里找即可。
