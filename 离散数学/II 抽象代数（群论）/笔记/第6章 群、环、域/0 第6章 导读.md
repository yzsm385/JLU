## 二、知识地图

```
代数系统（1 个运算 + 封闭）
   │  + 结合律
   ▼
 半群 ──+ 单位元──▶ 幺半群
   │  + 单位元 + 逆元
   ▼
  群 ──+ 交换律──▶ 阿贝尔群
   │
   ├── 子群 ──▶ 陪集 ──▶ 正规子群 ──▶ 商群
   │                │
   │                └──▶ 拉格朗日定理
   ├── 循环群（由 a 生成，周期决定大小）
   ├── 置换群 S_n ──▶ 交代群 A_n
   └── 同态 ──▶ 同态核 ──▶ 同态基本定理

环（2 个运算：加法群 + 乘法半群 + 分配律）
   ├── 交换环 ──+ 含 1 + 无零因子──▶ 整区 ──+ 非零元可逆──▶ 域
   └── 含 1 + 无零因子 + 非零元可逆 ──▶ 体 ──+ 交换──▶ 域
```

## 三、考试重点

> [!important] 老师划的范围
> 不考环同态、多项式、模格等；严格按 PPT 学习。

- **必考**：群的定义与五步验证、子群判别三条件、陪集与拉格朗日定理、同态基本定理
- **常考**：循环群生成元与 $\varphi(n)$、置换的轮换与奇偶、整区/体/域的判定
- **不学**：6.5.2 环同态、6.6 域的特征与素域、多项式、有限域（均无课件）

## 四、学习建议

1. 先吃透 6.1 的「封闭性 + 算律」，后面所有结构都是在这个骨架上加条件。
2. 6.2 与 6.3 是重点，证明题集中在这里。
3. 6.4 的三大同态定理要能自己画出「群 → 商群」的对应图。
4. 6.5 偏概念辨析，注意整区 / 体 / 域的包含关系（6.6 及以后无课件，不学）。
