# 6.2–6.4 横向结构全清单

> [!important] 这一页干什么
> 纵向链条是「半群 → 群 → 环 → 域」（靠**加条件**升级）。
> **横向结构不是升级，是同一个群从不同角度看。** 这一页把 PPT 里所有横向概念**收全**，
> 并标出每个的页码。共 **24 个概念，分 5 组**。

---

## 〇、先分清两条轴

```
纵向（升级轴）：加条件，越走越强
   半群 ──加壹──▶ 群 ──加乘法──▶ 环 ──加除法──▶ 域

横向（结构轴）：不加条件，换角度看同一个群
   一个群 G，可以从 5 个高度去看它 ↓
```

| 组 | 看的高度 | 回答什么问题 |
| --- | --- | --- |
| **A 组 · 元素级** | 单个元素 | 这个元素「多强」？ |
| **B 组 · 群级** | 整个群 | 这个群「什么类型」？ |
| **C 组 · 子结构级** | 群里面 | 里面藏着什么小群？ |
| **D 组 · 分割级** | 把群切开 | 怎么切成一样大的块？ |
| **E 组 · 映射级** | 群到群 | 两个群怎么对应？ |

## 一、24 个概念逐条（A–E 组）

### A 组 · 元素级（4 个）

#### A1 周期（PPT 6.3 P31）

> 若 $n$ 为适合 $a^n=1$ 的**最小正整数**，则称 $a$ 的周期为 $n$。
> 若所有幂都彼此不同，则称周期为**无穷大或 0**。

**加法群写法**（P42）：$na=0$ 的最小正整数 $n$。

**关键恒等式**（P41）：

$$\text{周期}(a)=\big|\langle a\rangle\big|$$

**三条性质**：

| 性质 | PPT |
| --- | --- |
| 单位元周期为 1 | P32 |
| $a$ 与 $a^{-1}$ 周期相同 | P32 |
| $n$ 元有限群中每个元素周期 $\le n$ | P33 |
| 周期整除 $\lvert G\rvert$ | P84 |
| $a^m=1\iff$ 周期 $\mid m$ | P39 定理 6.3.5 |

#### A2 幂等元（PPT 6.2 P21）

$a^2=a$ 的元素。**群里只有单位元是幂等元**（P21 原证）。

#### A3 零元（PPT 6.2 P22，标注「补充」）

$a\theta=\theta a=\theta$ 的元素。**群里没有零元**（P23）。

> [!warning] 这是范围外
> PPT 自己标了「补充」，且 6.2 后面没再用。**知道定义即可，不深究。**

#### A4 生成元（PPT 6.3 P27, P44）

若 $G=\langle a\rangle$，称 $a$ 为生成元。

| 群 | 生成元个数 | PPT |
| --- | --- | --- |
| 无限循环群 $\langle a\rangle$ | **恰好 2 个**：$a$、$a^{-1}$ | P44 |
| $n$ 元循环群 $\langle a\rangle$ | $\varphi(n)$ 个：$a^k$ 且 $(n,k)=1$ | P44 |
| $\mathbb{Z}_6$ | $\varphi(6)=2$：$1,5$ | P49 |
| $\mathbb{Z}_{12}$ | $\varphi(12)=4$：$1,5,7,11$ | — |

### B 组 · 群级（6 个）

#### B1 元数（PPT 6.2 P8）

群里元素个数。有限群 / 无限群。

> **PPT 用「元数」，不用「阶」。** 见 [[17 PPT 术语与范围]]。

#### B2 Abel 群 / 交换群（PPT 6.2 P48）

运算满足交换律。

| 是 Abel | 不是 Abel |
| --- | --- |
| $(\mathbb{Z},+)$、$(\mathbb{Q},+)$、$(\mathbb{R},+)$、$(\mathbb{C},+)$ | 实数域上 $n$ 阶非奇异矩阵（乘法） |
| $(\mathbb{Q}^*,\cdot)$、$(\mathbb{R}^*,\cdot)$、$(\mathbb{C}^*,\cdot)$ | $S_n$，$n\ge3$（P70） |
| 元数 1、2 的群 | |
| **所有循环群**（P30） | |

> [!tip] 一条铁律
> **循环 ⇒ Abel，但 Abel ⇏ 循环。**
> 反例：Klein 四元群 $V_4$ 交换但不循环（每个非单位元周期都是 2，没有 4 周期元）。

#### B3 循环群（PPT 6.3 P27）

$G=\langle a\rangle$。

**注意定义里没有「绕圈」**，只有「一个生成元就够」。

| | 有限循环群 | 无限循环群 |
| --- | --- | --- |
| 例 | $\mathbb{Z}_n$、$n$ 元循环群 | $\mathbb{Z}$、$n\mathbb{Z}$ |
| 元素 | $1,a,\dots,a^{n-1}$ | $\dots,a^{-1},1,a,\dots$ |
| 周期 | $n$ | 无穷大（0） |
| 子群 | $n$ 的每个正因数 $d$ 对应**恰好一个** $d$ 元子群（P81 结论 2） | 每个子群都是 $m\mathbb{Z}$ |

**循环群的子群仍是循环群**（P52）。

#### B4 置换 / 变换（PPT 6.2 P61）

- **变换**：$A$ 到 $A$ 自身的映射
- **置换**：$A$ 到 $A$ 自身的**一对一**变换

#### B5 $n$ 次对称群 $S_n$（PPT 6.2 P65, P69, P70）

$n$ 个元素的**全部**置换在乘法下成群，$|S_n|=n!$。

| $n$ | $S_n$ | 是否 Abel |
| --- | --- | --- |
| 1 | 1 元 | ✅ |
| 2 | 2 元 | ✅ |
| $\ge3$ | $n!$ 元 | ❌（P70） |

#### B6 $n$ 次交代群 $A_n$（PPT 6.2 P103）

全部**偶置换**，$|A_n|=n!/2$（$n>1$，P100）。

**$A_n$ 是群**（P103 五条验证）：含 $I$、偶×偶=偶封闭、结合律继承、逆仍为偶。

### C 组 · 子结构级（6 个）

#### C1 子群（PPT 6.3 P3）

$H\subseteq G$，且**按 $G$ 的同一个运算**仍是群。

> [!warning] P3 的 Note
> **子群的运算必须和大群一样。** $(\mathbb{C}^*,\cdot)$ 不是 $(\mathbb{C},+)$ 的子群。

#### C2 真子群 / 平凡子群 / 非平凡子群（PPT 6.3 P3, P5）

| 名字 | 定义 |
| --- | --- |
| **真子群** | $H\subsetneq G$ |
| **平凡子群** | $\{1\}$（单位子群）和 $G$ 本身 |
| **非平凡子群** | 除上述两个以外的 |

#### C3 三个判别条件（PPT 6.3 P7, P16, P21）

| | 条件 | 适用 |
| --- | --- | --- |
| **条件一** | (1) 封闭 (2) 逆在 (3) 非空 | 通用 |
| **条件二** | $a,b\in H\Rightarrow ab^{-1}\in H$，且 $H$ 非空 | 通用，**最好用** |
| **条件三** | $H$ **有限**非空 + 封闭 | **只对有限子集** |

> [!danger] 条件三的陷阱
> **条件三只在「有限」时成立。** 无限子集光封闭不够（$\mathbb{N}\subset\mathbb{Z}$ 对加法封闭但不是群）。
> 这就是你热身第 6 题「有限单射即满射」的同一个机制：**有限性当杠杆**。

#### C4 循环子群 $\langle a\rangle$（PPT 6.3 P26）

$a$ 的所有幂，**一定**是子群（定理 6.3.4）。

#### C5 正规子群（PPT 6.3 P73）

$$\forall g\in G:\ gH=Hg$$

等价写法（P74）：$\forall g\in G:\ gHg^{-1}\subseteq H$。

**判定捷径**：

| 情形 | 是否正规 | PPT |
| --- | --- | --- |
| $\{1\}$ 和 $G$ | ✅ 平凡正规 | P73 结论 1 |
| **Abel 群的任意子群** | ✅ | P73 结论 2 |
| **指数为 2 的子群** | ✅ | P94 |
| $S_3$ 中的 $A_3$ | ✅ | P76 |
| $S_3$ 中的 $\{I,(1\,2)\}$ | ❌ | P76 |
| 同态的核 | ✅ | 6.4 P24 |
| 同态下正规的像 | ✅ | 6.4 P50 |

#### C6 子群的运算（PPT 6.3 P13, P18, P20）

| 运算 | 结果 | PPT |
| --- | --- | --- |
| $H\cap K$ | **一定是**子群 | P18 |
| $H\cup K$ | **一般不是**子群（除非一个包含另一个） | P13 |
| $HK=\{hk\}$ | **当且仅当 $HK=KH$** 时是子群 | P20 |
| $gHg^{-1}$ | **一定是**子群 | P15 |

### D 组 · 分割级（5 个）

#### D1 陪集（PPT 6.3 P57, P58）

| | 定义 | 乘 $a$ 的位置 |
| --- | --- | --- |
| **右陪集** | $aH=\{ah\mid h\in H\}$ | 从**左**边乘 |
| **左陪集** | $Ha=\{ha\mid h\in H\}$ | 从**右**边乘 |

> 名字和位置是**反的**，PPT 固定约定，照抄。

#### D2 合同关系（PPT 6.3 P56）

- $a\equiv b$（**右** mod $H$）$\iff ab^{-1}\in H$
- $a\equiv b$（**左** mod $H$）$\iff a^{-1}b\in H$

**是等价关系**（P56），**陪集就是它的等价类**（P57）。

#### D3 陪集七条性质（PPT 6.3 P66–P72）

| # | 性质 |
| --- | --- |
| 1 | $\lvert aH\rvert=\lvert H\rvert$（P66，用消去律） |
| 2 | $H$ 本身也是 $H$ 的右陪集（$H=1H$，P67） |
| 3 | $aH=H\iff a\in H$（P68） |
| 4 | $a\in aH$（P69） |
| 5 | $b\in aH\Rightarrow aH=bH$（P70） |
| 6 | $aH=bH\iff a^{-1}b\in H$（P71） |
| 7 | **任意两个右陪集或相等或不相交**（P72） |

#### D4 指数 $[G:H]$（PPT 6.3 P82）

$$\boxed{[G:H]=\frac{|G|}{|H|}=\text{右陪集的个数}}$$

#### D5 右代表系（PPT 6.3 P83）

从每个右陪集挑一个代表，$g_1,\dots,g_s$，则

$$G=g_1H\cup g_2H\cup\cdots\cup g_sH\quad(\text{不交并})$$

#### ★ 拉格朗日定理（PPT 6.3 P77）

$$|G|=|H|\cdot[G:H]$$

**四条推论**（P81）：

1. 子群元数整除群元数
2. **但反过来不成立**：$n$ 的因数 $m$ 未必有 $m$ 元子群（$A_4$ 无 6 元子群，P79）
3. 循环群中，$n$ 的每个正因数**恰有一个**对应子群
4. 质数元数群**没有非平凡子群**

### E 组 · 映射级（3 个 + 商群）

#### E1 同态 / 同构 / 自同构（PPT 6.4 P3, P16, P20）

| 名字 | 条件 |
| --- | --- |
| **同态** | $\sigma(ab)=\sigma(a)\sigma(b)$，**不要求单射满射**（P3） |
| **同构** | 同态 + $G\to\sigma(G)$ 的 1-1 映射（P16） |
| **自同构** | $G$ 到 $G$ 自身的同构（P20） |

#### E2 核（PPT 6.4 P23）

$$N=\sigma^{-1}(1')=\{g\in G\mid\sigma(g)=1'\}$$

> [!warning] P23 的注
> 「$\sigma^{-1}(1')$ **只是一个记号，不代表逆映射**。」考场上别写成 $\sigma$ 的逆。

#### E3 商群 $G/N$（PPT 6.4 P31）

$N$ 正规时，全部陪集在**陪集乘法** $(aN)(bN)=abN$ 下成群。

$$|G/N|=[G:N]$$

#### ★ 三个同态定理（PPT 6.4 P24, P31, P36）

| 定理 | 内容 | 一句话 |
| --- | --- | --- |
| **第一** 6.4.2 | 核 $N$ 正规；$\sigma^{-1}(a')$ 是陪集；$G'$ 元素与 $N$ 的陪集一一对应 | 像 ↔ 块 |
| **第二** 6.4.3 | $N\trianglelefteq G$ ⇒ $G/N$ 成群；$\pi:a\mapsto aN$ 满同态，核 $=N$ | 块自己成群 |
| **第三** 6.4.4 | 满同态 $\sigma$，核 $N$ ⇒ $G'\cong G/N$ | 像 ≅ 块群 |

## 二、横向链条最终版（5 组 · 组内连线 · 组间接口 · 12 级脊柱）

> [!important] 这一节是全篇的核心
> 概念分 5 组只是**摆放**。真正让人懂的是**组内怎么连、组间怎么接**。
> 下面三层：**① 5 组的成员 → ② 组间 10 个接口 → ③ 12 级脊柱**。

### 2.1　五组成员一览

| 组 | 高度 | 成员 | 个数 |
| --- | --- | --- | --- |
| **A** | 元素 | A1 周期 · A2 幂等元 · A3 零元 · A4 生成元 | 4 |
| **B** | 群 | B1 元数 · B2 Abel · B3 循环 · B4 置换 · B5 $S_n$ · B6 $A_n$ | 6 |
| **C** | 子结构 | C1 子群 · C2 平凡/真 · C3 三判别 · C4 $\langle a\rangle$ · C5 正规 · C6 子群运算 | 6 |
| **D** | 分割 | D1 陪集 · D2 合同关系 · D3 七性质 · D4 指数 · D5 代表系 | 5 |
| **E** | 映射 | E1 同态/同构/自同构 · E2 核 · E3 商群 | 3 + 商群 |
| | | **合计** | **24** |

### 2.2　组内连线（每组内部怎么串起来）

**A 组内部**：四条互不干涉，都是「单个元素的属性」。

| 连线 | 内容 |
| --- | --- |
| A1 ← A2 | 幂等元 $\iff$ 周期为 1（$a^2=a\Rightarrow a=1$，6.2 P21） |
| A1 ← A3 | 有零元的半群里没有周期可言（群无零元，6.2 P23） |
| A1 → A4 | 生成元 $a$ 的周期**就是**整个循环群的元数（6.3 P41） |

**B 组内部**：一条**蕴含链**，越往右越强。

```
B1 元数  ←  任何群都有
   │
B2 Abel  ←  交换律（6.2 P48）
   │  + 一个生成元就够
B3 循环  ←  最强（6.3 P27）
   │
   ├─ 循环 ⇒ Abel（P30），Abel ⇏ 循环（V₄）
   │
B4 置换  ←  另一条独立的路：Sₙ 是「所有置换」
   │  取一对一
B5 Sₙ    ←  n! 元
   │  取偶的
B6 Aₙ    ←  n!/2 元，指数 2
```

> [!tip] B 组的两条线
> **线一（B1→B2→B3）**：越来越强的「交换性」。
> **线二（B4→B5→B6）**：置换群的「筛选」——全体 → 只要偶的。
> 两条线在 $S_3$ 交汇：$S_3$ 不 Abel、不循环，但它是 $S_n$。

**C 组内部**：从「最大」往「最特殊」筛。

```
C1 子群（定义）
   ├─ C2 按大小分：平凡 {1}、G；真子群；非平凡
   ├─ C3 按判据分：条件一 / 二 / 三（三只对有限）
   ├─ C4 按生成分：⟨a⟩（一定存在，P26）
   └─ C5 按对称性分：正规（最强的子群）
C6 是「运算」：交/并/积/共轭 之后还是不是子群
```

**D 组内部**：一条**流水线**，每步都靠前一步。

```
D2 合同关系（等价关系，6.3 P56）
   │ 等价类就是——
   ▼
D1 陪集 aH（P57）
   │ 性质七条（P66–P72）
   ▼
D3 其中第 1 条 |aH|=|H| ⇒ 每块一样大
   │ 数块数
   ▼
D4 指数 [G:H] = |G|/|H|（P82）
   │ 写成不交并
   ▼
D5 右代表系 G = g₁H ∪ … ∪ gₛH（P83）
   │ 两边取元数
   ▼
★ 拉格朗日 |G| = |H|·[G:H]（P77）
```

**E 组内部**：一条**往返**。

```
E1 同态 σ : G → G′
   │ 问：什么东西被压成 1′？
   ▼
E2 核 N = σ⁻¹(1′)（P23）
   │ N 一定正规（P24 第一定理）
   ▼
E3 商群 G/N（P31 第二定理）
   │ 像 ≅ 块群
   ▼
   G′ ≅ G/N（P36 第三定理）
   │ 让 G′=G
   ▼
E1′ 自同构（P20）
```

### 2.3　组间接口（★ 这是真正缺的那一块）

> 你说「太零散了」——零散就是因为没人告诉你**组与组之间在哪里焊住**。
> 下面 10 个接口，每一个都是「前一组的概念」直接变成「后一组的概念」。

| # | 从 | 到 | 接口定理 | PPT |
| --- | --- | --- | --- | --- |
| **I1** | A1 周期 | C4 $\langle a\rangle$ | $\text{周期}(a)=\lvert\langle a\rangle\rvert$ | 6.3 **P41** |
| **I2** | A4 生成元 | B3 循环群 | $G=\langle a\rangle$ $\iff$ $G$ 是循环群 | 6.3 P27 |
| **I3** | B2 Abel | C5 正规 | **Abel 群的任意子群都正规** | 6.3 **P73** |
| **I4** | C4 $\langle a\rangle$ | C1 子群 | $\langle a\rangle$ **一定是**子群（定理 6.3.4） | 6.3 P26 |
| **I5** | C1 子群 $H$ | D1 陪集 $aH$ | 用 $H$ 去「平移」整个 $G$ | 6.3 P57 |
| **I6** | D1 陪集 | C5 正规 | $H$ 正规 $\iff$ $\forall a:\ aH=Ha$ | 6.3 **P73** |
| **I7** | C5 正规 $N$ | E3 商群 $G/N$ | **不正规就做不出商群** | 6.4 **P31** |
| **I8** | E3 商群 | E2 核 | 自然同态 $\pi:a\mapsto aN$ 的核**恰好是** $N$ | 6.4 P31 |
| **I9** | E1 同态 | C1 / C5 | 子群的像仍是子群；**正规的像仍正规** | 6.4 P39, **P50** |
| **I10** | B6 $A_n$ | C5 正规 | $A_n$ 指数为 2 ⇒ **必然正规** | 6.3 **P94** |

> [!tip] 这 10 个接口怎么记
> 只要记住**两个「必然」**和**一个「必须」**：
> - $A_n$ **必然**正规（指数 2）
> - 核**必然**正规（第一同态定理）
> - 商群**必须**用正规子群（否则乘法不封闭）
>
> 其余接口都是「定义直接推」。

### 2.4　12 级脊柱（把上面全部压成一条线）

```
【A 组·元素】
 ①  元素 a
       │ 反复自乘，看什么时候回到 1
       ▼
 ②  a 的周期 n  ══════════════ |⟨a⟩|        【A1 / 6.3 P31,P41】
       │ 生成                                    ← 接口 I1
       ▼
【C 组·子结构】
 ③  循环子群 ⟨a⟩  ─────── 一定是子群        【C4 / P26】← 接口 I4
       │ 去掉「循环」这个限制
       ▼
 ④  子群 H  ─────────── 判别条件一/二/三     【C1,C3 / P3,P7,P16,P21】
       │ 拿 H 平移整个群                          ← 接口 I5
       ▼
【D 组·分割】
```

## 三、把 24 个概念挂到 $S_3$ 上

$$S_3=\{I,(1\,2),(1\,3),(2\,3),(1\,2\,3),(1\,3\,2)\},\quad |S_3|=6$$

| A4 | 生成元 | $S_3$ **不是**循环群，无生成元 |
| B1 | 元数 | 6 |
| B2 | Abel？ | ❌（$(1\,2)(1\,3)\ne(1\,3)(1\,2)$） |
| B3 | 循环？ | ❌ |
| B4 | 置换 | 6 个，全是 $\{1,2,3\}$ 的置换 |
| B5 | $S_3$ | 就是它自己 |
| B6 | $A_3$ | $\{I,(1\,2\,3),(1\,3\,2)\}$，3 元 |
| C1 | 子群 | **共 6 个**（P85） |
| C2 | 平凡子群 | $\{I\}$、$S_3$ |
| C4 | 循环子群 | $\langle(1\,2)\rangle$、$\langle(1\,3)\rangle$、$\langle(2\,3)\rangle$（各 2 元）、$A_3$（3 元） |

| 元数 | 子群 | 正规？ |
| --- | --- | --- |
| 1 | $\{I\}$ | ✅ |

## 四、最容易混的五对

| 对 | 区别 | 一句话 |
| --- | --- | --- |
| **子群 vs 陪集** | 子群是群，陪集一般只是集合 | 只有含 $I$ 的那块是子群 |
| **元数 vs 周期** | 元数是群的，周期是元素的 | $\lvert\langle a\rangle\rvert=$ 周期$(a)$ |
| **指数 vs 元数** | 指数是块数，元数是块里元素数 | $|G|=|H|\times[G:H]$ |
| **正规 vs 子群** | 正规是子群里更特殊的一类 | 正规 ⟺ 左右陪集相同 |
| **同态 vs 同构** | 同构多了双射 | 同态会压缩，同构不会 |
