- [ ] 格的定义（偏序格）：任意**两个**元素都有 $\inf$ 和 $\sup$
- [ ] 代数格的三条：交换、结合、吸收
- [ ] 有界格 / 有余格各一句话
- [ ] 布尔代数 = ？

<details><summary>对答案（写完再点）</summary>

1. $x\le x$；$x\le y$ 且 $y\le x\Rightarrow x=y$；$x\le y$ 且 $y\le z\Rightarrow x\le z$。
2. 偏序集 $(L,\le)$，对任意 $a,b\in L$，$\{a,b\}$ 在 $L$ 中都有最大下界 $a\wedge b$ 和最小上界 $a\vee b$。**是「任意两个元素」，不是「任意子集」。**
3. $a\times b=b\times a$；$(a\times b)\times c=a\times(b\times c)$；$a\times(a\oplus b)=a$、$a\oplus(a\times b)=a$（两条都写）。
4. 有界格：有最小元 $0$ 和最大元 $1$，即 $\forall a,\ 0\le a\le 1$。有余格：有界格且**每个元素都有补元** $a'$，满足 $a\wedge a'=0$、$a\vee a'=1$。
5. **有余分配格**，记 $(B,\cdot,+,\bar{\ },0,1)$，且 $B$ 至少含两个元素。

</details>

### 35–70′　7.2 格的定义与子格（35 分钟）

材料：[[7.2 格的定义]]；PPT P6–P25；教材 P242–245

- [ ] ★ 偏序格定义（见开场第 2 条）。
- [ ] ★ 代数格三条 + **吸收律推出幂等律**（PPT P14 有完整证明，看一眼即可）。
- [ ] ★ 两种定义等价，转换公式**必须背死**：

$$a\le b\iff a\wedge b=a\iff a\vee b=b$$

- [ ] ★ 子格：$(S,\le)$ 自己也是格 —— 两元素的 $\inf/\sup$ **必须在 $S$ 内取到**。
- [ ] ★ 代数子格：对 $\wedge,\vee$ **封闭**。代数子格 ⇒ 偏序子格，反之**不成立**（PPT P23）。

**判定练习 A：是不是格（6 题，30 秒一题）**

| # | 偏序集 | 是格？ | 理由 |
| --- | --- | --- | --- |
| 1 | $(\mathcal{P}(S),\subseteq)$ | | |
| 2 | $(\mathbb{Z}^+,\mid)$ | | |
| 3 | $S_{24}=\{1,2,3,4,6,8,12,24\}$ 按 $\mid$ | | |
| 4 | $S=\{1,2,3,6,12,24,36\}$ 按 $\mid$ | | |
| 5 | $\{1,2,3\}$ 按 $\mid$ | | |
| 6 | 一条链 $a<b<c$ | | |

<details><summary>答案（做完再点）</summary>

1. **是**。$\sup=A\cup B$，$\inf=A\cap B$。
2. **是**。$\sup=\operatorname{lcm}$，$\inf=\gcd$。
3. **是**。24 的全部因数都在，$\gcd/\operatorname{lcm}$ 不会跑出去。
4. **不是**。$\sup\{24,36\}=\operatorname{lcm}=72\notin S$，$24,36$ 在集合内没有上界。
5. **不是**。$2,3$ 没有公共上界。
6. **是**。$\inf=\min$，$\sup=\max$，全序集一定是格。

> 判据一句话：**任意两元素的 $\gcd/\operatorname{lcm}$（或 $\cap/\cup$）必须还落在集合里**。跑出去一个，就不是格。

</details>

**判定练习 B：子格（PPT P24–P25 原题）**

- [ ] PPT P24：$S_2=\{a_1,a_2,a_4,a_8\}$ 是**偏序子格**，但**不是代数子格**，因为 $a_2\times a_4=a_6\notin S_2$。
- [ ] PPT P25：$S_1=\{c,e,g,f\}$ **不是**子格；$S_2=\{a,b,g,f\}$ **是**子格。

> [!warning] 最容易错的地方
> 子格不是「子集 + 继承偏序」就完事。$S_2$ 在子集里看是格，但两个元素的**下确界跑到了子集外面**，所以不是代数子格。
> 考试写理由就写这一句：**「$a_2\wedge a_4=a_6\notin S_2$，对 $\wedge$ 不封闭」**。

### 70–95′　7.3 格的性质与同态（25 分钟）

材料：[[7.3 格的性质]]；PPT P26–P45；教材 P246–252

> [!note] 对偶原理已删除
> PPT P26 明写 `7.3.1 对偶原理（删除）`。只需知道「格的命题成对出现，$\le$ 与 $\ge$、$\wedge$ 与 $\vee$、$0$ 与 $1$ 互换后仍成立」，**不背、不练**。省下的时间给下面的分配不等式。

- [ ] ★ 定理 7.3.1：$a\le b\iff a\times b=a\iff a\oplus b=b$（就是 7.2 的换算公式，必须条件反射）。
- [ ] ★ 保序性（定理 7.3.2）：$b\le c\Rightarrow a\wedge b\le a\wedge c$，$a\vee b\le a\vee c$。
- [ ] ★★ **分配不等式**（定理 7.3.3）——一般格只有不等式，没有等号：

$$a\vee(b\wedge c)\le(a\vee b)\wedge(a\vee c),\qquad a\wedge(b\vee c)\ge(a\wedge b)\vee(a\wedge c)$$

- [ ] ★ 定理 7.3.4（一个漂亮的充要条件，可能出证明）：

$$a\le b\iff a\vee(b\wedge c)\le b\wedge(a\vee c)$$

- [ ] ★ 格同态：$f(a\wedge b)=f(a)\wedge f(b)$，$f(a\vee b)=f(a)\vee f(b)$。**两个都要**。
- [ ] ★ 格同构 = 同态 + 双射；等价说法：$a\le b\iff f(a)\le f(b)$。
- [ ] ★★ **同态 ⇒ 保序，但保序 ⇏ 同态**（定理 7.3.5 + PPT P38 三个反例）。

**必背反例（保序但不同态）**

$L=\mathcal{P}(\{1,2\})=\{\varnothing,\{1\},\{2\},\{1,2\}\}$，$L'=\{0<c<1\}$ 是三元链：

$$f(\varnothing)=0,\quad f(\{1\})=f(\{2\})=c,\quad f(\{1,2\})=1.$$

$f$ 保序，但

$$f(\{1\}\wedge\{2\})=f(\varnothing)=0\ne c=c\wedge c=f(\{1\})\wedge f(\{2\}),$$

所以**不是**格同态。

- [ ] ◯ $n$ 维格：$\mathcal{P}(\{1,2,3\})\cong(\{0,1\}^3,\le)$，Hasse 图是立方体（P45）。看一眼即可。

> [!tip] 一句话区分
> **同态管运算，保序管顺序。** 运算比顺序细，所以同态能推保序，反过来推不动。

- 产出：分配不等式默写一遍 + 上面那个反例手写一遍（4 行）。

### 95–130′　7.4 几种特殊的格（35 分钟 · 今晚最值钱的一段）

材料：[[7.4 几种特殊的格]]；PPT P46–P65；教材 P253–259

- [ ] ★ 引理 7.4.1：格的**有限非空**子集必有 $\inf/\sup$；无限子集不成立（$\mathbb{Z}^+$ 中正偶数无上确界）。
- [ ] ★ 有界格：有 $0,1$。**有限格一定有界，有界格不一定有限**。
- [ ] ★ 有界格的 $0$-$1$ 律：$a\vee1=1$，$a\wedge0=0$，$a\vee0=a$，$a\wedge1=a$。
- [ ] ★ 补元：$a\wedge a'=0$ 且 $a\vee a'=1$。**$0$ 的唯一补元是 $1$，反之亦然**（引理 3）。
- [ ] ★ 有余格：**每个**元素都有补元。补元**不一定唯一**（$M_3$ 里 $a$ 的补元是 $b$ 和 $c$）。
- [ ] ★ 分配格：两个分配律**验一个就够**（PPT P56 有互推）。
- [ ] ★★ **判定定理**：格是分配格 $\iff$ 不含与 $M_3$ 或 $N_5$ 同构的子格。
- [ ] ★ 链一定是分配格；但 $>2$ 个元素的链**不是**有余格（中间元素没补元）。
- [ ] ★★ **定理 7.4.2**：分配格中 $a\wedge c=b\wedge c$ 且 $a\vee c=b\vee c$ $\Rightarrow a=b$。
- [ ] ★★ **推论（补元唯一）**：有余分配格中补元唯一。

**$M_3$ 与 $N_5$（各画 3 遍，必须闭卷能画）**

```
     M3（钻石格）              N5（五角格）
         1                        1
      /  |  \                     |
     a   b   c                    c
      \  |  /                     |
         0                        b
                                  |
                                  a
                                  |
                                  0
```

| | 有界 | 有余 | 分配 | 模 | 一句话理由 |
| --- | --- | --- | --- | --- | --- |
| $M_3$ | ✅ | ✅ | ❌ | ✅ | $a\vee(b\wedge c)=a$，$(a\vee b)\wedge(a\vee c)=1$ |
| $N_5$ | ✅ | ✅ | ❌ | ❌ | $a\vee(c\wedge b)=a$，$(a\vee c)\wedge b=b$ |

> [!warning] 三个高频错
> 1. 说「$N_5$ 是模格」→ 错。**$N_5$ 是最小非模格**，$M_3$ 才是模的。
> 2. 说「$M_3$ 不是有余格」→ 错。$M_3$ **是**有余格，只是补元不唯一。
> 3. 说「有余格一定分配」→ 错。**「有余」与「分配」互不包含**，$M_3$、$N_5$ 都是有余但非分配。

**必做证明：补元唯一（定理 7.4.2 推论）**

设 $a',a''$ 都是 $a$ 的补元，则 $a\wedge a'=a\wedge a''=0$，$a\vee a'=a\vee a''=1$。由定理 7.4.2 直接得 $a'=a''$。

> 考试要展开就写定理 7.4.2 的链：
> $$a'=a'\wedge1=a'\wedge(a\vee a'')=(a'\wedge a)\vee(a'\wedge a'')=0\vee(a'\wedge a'')=a'\wedge a'',$$
> 对称地 $a''=a'\wedge a''$，故 $a'=a''$。**关键一步是分配律**，不分配就没有唯一性。

**PPT 原题速刷（对答案用，别先看）**

- P57：$L_1,L_2$ 是分配格，$L_3$（钻石）、$L_4$（五角）不是。
- P58：给出的几个格**都不是**分配格。
- P63：$\mathcal{P}(A)$ 中每个元素的余元素 **A. 存在且唯一**。
- P64 四问：① 有界格不一定有限；余元素不一定唯一。② 任意链都是分配格，但不一定是有余分配格。③ 有界分配格中若有余元素，则**一定唯一**。④ $(\mathbb{N},\le)$ **不是**有余分配格（无最大元）。

### 130–150′　7.5 布尔代数（20 分钟 · 只到子代数）

材料：[[7.5 布尔代数]]；PPT P66–P81；教材 P260–271

> PPT 只到「亨廷顿公理 + 子代数」。**表示定理、布尔同态不考，别往后翻。**

- [ ] ★ 定义：**有余分配格** = 布尔代数，记 $(B,\cdot,+,\bar{\ },0,1)$，**至少两个元素**（$0\ne1$）。
- [ ] ★★ **亨廷顿四组公理**（PPT P73，闭卷默写）：

| | 公理 |
| --- | --- |
| H1 | $a\cdot b=b\cdot a$，$a+b=b+a$（交换） |
| H2 | $a\cdot(b+c)=(a\cdot b)+(a\cdot c)$，$a+(b\cdot c)=(a+b)\cdot(a+c)$（分配，**两个方向都要**） |
| H3 | 存在 $0,1$：$a\cdot1=a$，$a+0=a$（同一） |
| H4 | $a+\bar a=1$，$a\cdot\bar a=0$（互补） |

- [ ] ★ 布尔代数里**补元唯一**（因为分配），所以 $\bar a$ 写得理直气壮。
- [ ] ★ De Morgan（定理 7.4.1 的布尔版）：

$$\overline{a\cdot b}=\bar a+\bar b,\qquad\overline{a+b}=\bar a\cdot\bar b$$

- [ ] ★ 偏序五种等价说法（P72，可能出判断）：

$$a\le b\iff a+b=b\iff a\cdot b=a\iff a\cdot\bar b=0\iff\bar a+b=1$$

- [ ] ★★ **子代数 vs 子格**（今晚第二个高频错点）：

| | 要求 |
| --- | --- |
| 子格 | 对 $\wedge$、$\vee$ 封闭 |
| 子代数 | 对 $\cdot$、$+$、$\bar{\ }$ **三种**都封闭（$0,1$ 自动含） |

**PPT P80–P81 三个例子（必看，考判断就考这个）**

设 $S=\{a,b,c\}$，$\mathcal{P}(S)$ 是布尔代数：

- $S_1=\{\varnothing,\{a\},\{b,c\},\{a,b,c\}\}$ → **是**子代数（补封闭：$\{a\}$ 的补是 $\{b,c\}$，在里面）。
- $S_2=\{\varnothing,\{a\},\{b\},\{a,b\},\{a,b,c\}\}$ → **是子格，不是子代数**（$\{a\}$ 的补 $\{b,c\}\notin S_2$）。
- $S_3=\{\varnothing,\{a\}\}$ → 自身是布尔代数，但**不是** $\mathcal{P}(S)$ 的子代数（不含 $\mathcal{P}(S)$ 的最大元 $S$）。

> [!tip] 判据一句话
> **子格差一个「补」。** 判断题里看到「对交、并封闭」先别急着打勾，补一下试试，补跑了就不是子代数。

- [ ] ◯ 只记结论不推导：有限布尔代数阶为 $2^n$，所以 3 元、6 元的布尔代数**不存在**。
