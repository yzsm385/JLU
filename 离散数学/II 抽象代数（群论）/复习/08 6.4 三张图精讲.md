# 6.4 三张图精讲 + 良定义

> [!important] 为什么单独写这一页
> 6.4 是全章最抽象的一节，而 PPT 的 25、32、38 三张图**就是三个同态定理本身**。
> 图看懂了，定理就不用背；图看不懂，背了也会写串。

## 〇、先补三个基础，否则图一定看不懂

### 0.1 陪集怎么写：特解 + 核

**问题**：$\sigma:\mathbb{Z}\to\mathbb{Z}_6$，$x\mapsto x\bmod6$。求 $\sigma^{-1}(2)$。

**错误答案**：$6\mathbb{Z}$（那是核，是 $\sigma^{-1}(0)$）。
**正确答案**：$2+6\mathbb{Z}=\{\dots,-4,2,8,14,\dots\}$。

**为什么**：解 $x\equiv2\pmod6$，先找一个特解 $x_0=2$，再加上核里的全部元素。

$$\sigma^{-1}(a')=\underbrace{a}_{\text{特解}}+\underbrace{N}_{\text{核}}=\underbrace{aN}_{\text{陪集}}$$

> [!tip] 和线性代数一模一样
> 解 $Ax=b$：解集 $=x_0+\ker A$（特解 + 齐次解）。
> 求 $\sigma^{-1}(a')$：原像集 $=a+N$（特解 + 核）。
> **同一个结构**：非齐次解 = 特解 + 齐次通解。

**验证表**（$\sigma:\mathbb{Z}\to\mathbb{Z}_6$）：

| $a'$ | $\sigma^{-1}(a')$ | 陪集写法 |
| --- | --- | --- |
| 0 | $\{\dots,-6,0,6,12,\dots\}$ | $0+6\mathbb{Z}=N$ |
| 2 | $\{\dots,-4,2,8,14,\dots\}$ | $2+6\mathbb{Z}$ |
| 5 | $\{\dots,-1,5,11,17,\dots\}$ | $5+6\mathbb{Z}$ |

每个原像都是「把核平移一下」，**所以原像一定是陪集，不可能是别的形状**。这就是定理 6.4.2 第 3 条。

### 0.2 满射看的是「像 = 陪域」

| 映射 | 陪域 | 像 | 满射？ |
| --- | --- | --- | --- |
| 平凡同态 $\sigma(x)\equiv1'$ | $G'$ | $\{1'\}$ | ❌ 除非 $G'$ 只有 $1'$ |
| $x\mapsto x\bmod n$ | $\mathbb{Z}_n$ | $\mathbb{Z}_n$ | ✅ |
| $n\mapsto i^n$ | $\mathbb{C}^*$ | $\{1,i,-1,-i\}$ | ❌ |
| $n\mapsto i^n$ | $\{1,i,-1,-i\}$ | $\{1,i,-1,-i\}$ | ✅ |

**满射 = 像把陪域填满**，不是「原像都被用上了」（后者恒真，任何映射都满足）。

### 0.3 良定义：PPT 没这个词，但做的是同一件事

> [!note] 你说得对，PPT 里没有「良定义」三个字
> PPT 用的是更具体的说法：
> - 第 28 页：直接证 $\sigma^{-1}(a')=Na$（原像恰好是一个陪集）
> - 第 30 页 引理 1：证 $AB=aNbN=abN$（陪集乘积仍是陪集）
>
> 这两步就是「良定义」的全部内容，只是现代教材给它起了个名字。

**良定义是什么**：想定义一个函数，但定义方式是「先挑一个代表元，再按公式算」。代表元不唯一，所以要验证：**换个代表元，结果不变**。验证通过，才叫良定义。

**最小反例（一定要记住这个）**：
定义 $f\!\left(\frac ab\right)=a+b$。问：这是函数吗？
$f\!\left(\frac12\right)=3$，$f\!\left(\frac24\right)=6$。可 $\frac12=\frac24$ 是同一个数，却算出两个值。**不是函数，不良定义。**

**陪集版本的反例**：
定义 $h:\mathbb{Z}_6\to\mathbb{Z}_4$，$h([x]_6)=[x]_4$。
$[0]_6=[6]_6$（同一个陪集），但 $[0]_4=0$，$[6]_4=2$。**不良定义。**

**陪集版本的正例**：
定义 $g:\mathbb{Z}_6\to\mathbb{Z}_3$，$g([x]_6)=[x]_3$。
若 $[x]_6=[y]_6$，则 $6\mid(x-y)$，故 $3\mid(x-y)$，即 $[x]_3=[y]_3$。**良定义。**

**商群乘法为什么良定义**：
定义 $(aN)(bN)=abN$。若换成 $a'=an$、$b'=bm$，则
$$a'b'N=anbmN\overset{N\text{ 正规}}{=}ab(n'm)N=abN.$$
中间那步 $nb=bn'$ 正是正规性。**非正规时这一步断掉，乘法就假了。**

## 一、PPT 第 25 页图：第一同态定理（一一对应）

### 图

```
        G                              G'
   ┌─────────────┐                ┌──────────┐
   │  1          │──── σ ────────→│  1'      │
   │  N ∋ 1      │──── σ ────────→│  1'      │  ← 整个 N 压成 1'
   │  aN = Na    │──── σ ────────→│  a'      │
   │  bN = Nb    │──── σ ────────→│  b'      │
   │    ⋮        │                │   ⋮      │
   └─────────────┘                └──────────┘
      |G| 个元素                    |G'| 个元素
```

### 怎么读这张图

**左边是元素，右边是元素，但左边被「打包」了。**

- 左边每个虚线框是**一个陪集**（$N$、$aN$、$bN$…），每个陪集里有 $|N|$ 个元素。
- 每个陪集**整体**映到右边**一个**元素。
- 所以：**左边 $|G|$ 个元素，右边只有 $|G'|$ 个元素**，关系是
$$|G|=|N|\cdot|G'|,\qquad |G'|=[G:N].$$

**这就是拉格朗日定理在 6.4 里的样子。**

### PPT 那 4 条文字，对应的就是图的 4 个部位

| PPT 第 25 页的话 | 图上的位置 |
| --- | --- |
| 1、前提：$\sigma$ 是到 $G'$ **上**的同态 | 保证右边**每个点**都有箭头来 |
| 2、$N=\sigma^{-1}(1')$ 是正规子群 | 左边最上面那个框，含 $1$ |
| 3、$\sigma^{-1}(a')$ 是 $N$ 的一个陪集 | 每个虚线框就是某个 $a'$ 的原像 |
| 4、$G'$ 的元素 ↔ 陪集 一一对应 | 右边点与左边框**一对一** |

### 为什么写 $aN=Na$

因为 $N$ 正规，左右陪集相等，所以「用哪个当代表都一样」。这句是**良定义的另一种写法**。

### 关键理解：图里「多对一」和「一一对应」同时成立

- $\sigma$ 本身：$G\to G'$ 是**多对一**（一个陪集里所有元素映到同一点）。
- 但「陪集 → 点」是**一一对应**。

> 这就是「压缩」的精确含义：**元素层面多对一，陪集层面一对一。**

## 二、PPT 第 32 页图：第二同态定理（坍缩）

### 图

```
          σ : a ↦ aN
      G                        G/N
  ┌─────────┐              ┌─────────┐
  │  a      │─────────────→│  aN     │
  │  an     │─────────────→│         │  同一陪集里所有元素
  │  an'    │─────────────→│         │  全部落到同一个点
  ├─────────┤              ├─────────┤
  │  b      │─────────────→│  bN     │
  │  bm     │─────────────→│         │
  ├─────────┤              ├─────────┤
  │  1      │─────────────→│  N      │  ← N 是 G/N 的单位元
  └─────────┘              └─────────┘
```

### 怎么读这张图

**这次右边不是抽象群 $G'$，而是「陪集本身组成的集合」$G/N$。**

- $G/N$ 的元素**就是**陪集：$N,\ aN,\ bN,\dots$
- 映射 $\sigma(a)=aN$ 把每个元素送到**它所在的陪集**
- 一个陪集里的 $|N|$ 个元素，全被送到**同一个点**

> **这张图是「坍缩」：把每个陪集压成一个点。**

### 三个必须看懂的点

1. **$G/N$ 的元素个数 = $[G:N]$**（不是 $|G|$）。
2. **$N$ 是 $G/N$ 的单位元**：因为 $N\cdot aN=aN$。核映到单位元，天经地义。
3. **$\sigma$ 的核是 $N$**：$\{g\mid gN=N\}=\{g\mid g\in N\}=N$。PPT 第 33 页就这么证的。

### 和第 25 页图的关系

| | 第 25 页 | 第 32 页 |
| --- | --- | --- |
| 右边是什么 | 抽象群 $G'$ | 陪集集合 $G/N$ |
| $\sigma$ 从哪来 | 题目给的同态 | 自己造的 $\pi(a)=aN$ |
| 结论 | 陪集 ↔ $G'$ 的元素 | $G/N$ 本身是群 |

**第 25 页说「陪集和 $G'$ 一一对应」，第 32 页说「陪集自己就能组成群」。两句话一拼，就是第 38 页。**

## 三、PPT 第 38 页图：第三同态定理（三角形 / 因子化）

### 图

```
                 σ
        G ─────────────────→ G'
        │                     │
        │                     │
   τ    │                     │  γ  （同构）
 a↦aN   │                     │
        ↓                     ↓
       G/N ──────────────────┘
              （同一个对象）
```

### 怎么读这张图

**$\sigma$ 被拆成两步：先坍缩，再一一对应。**

$$\sigma=\gamma\circ\tau$$

- $\tau:G\to G/N$，$\tau(a)=aN$：**自然同态**（坍缩，多对一）
- $\gamma:G/N\to G'$，$\gamma(aN)=\sigma(a)$：**同构**（一一对应）
- 先走 $\tau$ 再走 $\gamma$，等价于直接走 $\sigma$

> 这张图叫**交换图**：两条路径到达同一个终点，结果相同。

### 这张图就是基本定理的证明骨架

| 图上要证的 | 就是 | 用到的条件 |
| --- | --- | --- |
| $\gamma$ 有意义（良定义） | $aN=bN\Rightarrow\sigma(a)=\sigma(b)$ | $N$ 正规 + 核定义 |
| $\gamma$ 是同态 | $\gamma(aNbN)=\gamma(abN)=\sigma(ab)$ | $\sigma$ 同态 |
| $\gamma$ 单射 | $\gamma(aN)=1'\Rightarrow a\in N$ | 核定义 |
| $\gamma$ 满射 | 每个 $\sigma(a)$ 都有原像 $aN$ | $\sigma$ 满射 |

**四个格子，正好对应「良定义 / 同态 / 单射 / 满射」四个验证点。**

### 线性代数里的同一张图

```
        T
   V ──────────→ W
   │             │
 π │             │ ≅
   ↓             ↓
  V/ker T ──────→ Im T
```

**完全一样**。你在线代里画过这张图，只是当时没觉得它重要。

## 五、同态的性质（PPT 第 14–15、39–51 页，前面漏讲的）

### 5.1 基本三条（定理 6.4.1）

1. $\sigma(G)$ 是群
2. $\sigma(1)=1'$
3. $\sigma(a^{-1})=\sigma(a)^{-1}$

### 5.2 推论（PPT 第 14–15 页）

| 性质 | 内容 | 用途 |
| --- | --- | --- |
| 逆的像 | $\sigma(a)=\sigma(b)\Rightarrow\sigma(a^{-1})=\sigma(b^{-1})$ | 判断题常考 |
| 循环群的像 | $G=\langle a\rangle$，$\sigma$ 满同态 $\Rightarrow G'=\langle\sigma(a)\rangle$ 仍循环 | 随堂练习第 7 题 |
| 幂的像 | $\sigma(a^t)=\sigma(a)^t$ | 计算题 |

### 5.3 子群的四条结论（PPT 第 39–44 页）

| # | 结论 | 直观 |
| --- | --- | --- |
| 1 | $H\le G\Rightarrow\sigma(H)\le G'$ | 子群映成子群 |
| 2 | $H'\le G'\Rightarrow\sigma^{-1}(H')\le G$ | 子群拉回来还是子群 |
| 3 | $\sigma^{-1}(\sigma(H))=HN$ | **会膨胀**，多出 $N$ 的部分 |
| 4 | $N\subseteq H\Rightarrow\sigma^{-1}(\sigma(H))=H$ | 包含核时才不膨胀 |

> 结论 3 是最反直觉的：先取像再取原像，一般**回不到 $H$**，会变成 $HN$。
> 例：$\mathbb{Z}\to\mathbb{Z}_6$，$H=2\mathbb{Z}$，则 $\sigma^{-1}(\sigma(H))=\sigma^{-1}(\{0,2,4\})=2\mathbb{Z}+6\mathbb{Z}=2\mathbb{Z}$。
> 但如果 $H=\{0\}$，$\sigma^{-1}(\sigma(\{0\}))=6\mathbb{Z}\ne\{0\}$，**膨胀了**。

### 5.4 子群对应定理（定理 6.4.5，PPT 第 48–51 页）

> $G'$ 的子群 ↔ 包含 $N$ 的 $G$ 的子群，**一一对应**，且
> - 大群对应大群，小群对应小群（保序）
> - **正规子群对应正规子群**

这条是「结构传递」：$G'$ 的子群结构完全由 $G$ 里「包含核的那些子群」决定。

## 六、自测（合上书）

1. $\sigma:\mathbb{Z}\to\mathbb{Z}_{12}$，$x\mapsto x\bmod12$。写出 $\sigma^{-1}(5)$、核、$[G:N]$。
2. 为什么 $\sigma^{-1}(a')$ 一定是陪集，而不是随便一堆元素？
3. 第 25 页图里，左边有几个虚线框？右边有几个点？两者什么关系？
4. 第 38 页图里，$\tau$ 和 $\gamma$ 各是什么映射？哪个是多对一？
5. 定义 $h([x]_6)=[x]_4$ 良定义吗？为什么？

<details><summary>答案</summary>

1. $\sigma^{-1}(5)=5+12\mathbb{Z}$；核 $=12\mathbb{Z}$；$[G:N]=12$。
2. 因为解 $x\equiv a\pmod n$ 的解集 = 特解 + 齐次解 = $a+N$，形状被核决定。
3. 左边 $[G:N]$ 个框（每个含 $|N|$ 个元素），右边 $|G'|$ 个点，**数目相等，一一对应**。
4. $\tau(a)=aN$ 自然同态（多对一，坍缩）；$\gamma(aN)=\sigma(a)$ 同构（一一对应）。
5. 不良定义。$[0]_6=[6]_6$，但 $[0]_4\ne[6]_4$。

</details>
