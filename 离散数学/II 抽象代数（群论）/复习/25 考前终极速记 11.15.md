## ★ 0. 最后 30 分钟：只看这 15 行

1. **元数** = 元素个数；**周期** = 单个元素的周期 $=|\langle a\rangle|$；**指数** = 陪集个数 $=|G|/|H|$
2. $a$ 的周期为 $n$ ⇒ $a^m$ 的周期 $=\dfrac{n}{\gcd(n,m)}$
3. **$\mathbb{Z}_n$（加法）永远循环**，生成元 $\varphi(n)$ 个
4. **$\mathbb{Z}_n^{*}$（乘法）才要判循环**：$n=1,2,4,p^k,2p^k$ 才循环，否则**生成元 0 个**
5. 置换**周期** = 不相杂轮换长度的 $\operatorname{lcm}$；求 $\sigma^k$：先算周期 $m$，再取 $k\bmod m$
6. 置换**奇偶**：$n-k$（$k$ = 轮换个数，**含单轮换**）；$n-k$ 奇 ⇒ 奇置换
7. **整区** = 交换 + 含 $1$（$1\ne0$）+ 无零因子。**三者缺一不可**
8. **有限整区 ⇒ 域**（单向！域不必有限：$\mathbb{Q},\mathbb{R},\mathbb{C}$）
9. **消去环里加法周期只能是素数**（见到 4、6、8 直接判错）
10. 整区里**幂等元恰好 2 个**：$0$ 和 $1$
11. **有限格必有界**；但**有界 ≠ 格**（格要每对有确界）
12. **有余 + 分配 ⇒ 余元素唯一**（**不能倒推！** 由"唯一"推不出"有余"）
13. **布尔代数** = 有界 + 有余 + 分配 + $0\ne1$
14. **PPT 记号**：核 $N=\sigma^{-1}(1')$、像 $\sigma(G)$、余元素 $\bar a$、元数/周期（**不写"阶"**）
15. **循环群 ⇒ 交换群 ⇒ 群**，反向全不成立。反例：$V_4$ 交换不循环；$S_3$ 群不交换

## ★ 1. 三个必须分清的数（错过 4 次）

以 $\mathbb{Z}_{18}$ 中 $\langle6\rangle=\{0,6,12\}$ 为例：

| 名词 | 是什么 | 本例 |
| --- | --- | --- |
| **元数** | 群/子群里**元素的个数** | $3$ |
| **周期** | **单个元素**的周期 $=|\langle a\rangle|$ | $6$ 的周期是 $3$ |
| **指数** | **陪集的个数** $=|G|/|H|$ | $18/3=6$ |

> 元数描述**群**，周期描述**元素**，指数描述**子群占几摞**。
> 桥梁：**周期$(a)=|\langle a\rangle|$**（PPT 6.3 P41）。

## ★ 2. 循环群三问（一字不差地背）

| 问 | 答 |
| --- | --- |
| $n$ 元循环群有几个子群 | $n$ 的**正因数个数** |
| $d\mid n$，$d$ 元子群有几个 | **恰好 1 个**（$=\langle n/d\rangle$） |
| $n$ 元循环群生成元几个 | $\varphi(n)$，具体是 $a^k$ 且 $(k,n)=1$ |
| $\mathbb{Z}_n$ 循环吗 | **永远循环**（加法群） |
| $\mathbb{Z}_n^{*}$ 循环吗 | $n=1,2,4,p^k,2p^k$ 才循环 |
| $\mathbb{Z}_n^{*}$ 非循环时生成元 | **0 个** |

> [!danger] 11/14 模拟卷踩的坑
> 问"$\mathbb{Z}_{30}$ 生成元几个"，答了 0。**$\mathbb{Z}_{30}$ 是加法群，一定循环，答案 $\varphi(30)=8$。**
> **判循环的规则只对带星号的乘法群成立。**

**必记的非循环**：$\mathbb{Z}_{8}^{*},\mathbb{Z}_{12}^{*},\mathbb{Z}_{16}^{*},\mathbb{Z}_{20}^{*}$（$\cong\mathbb{Z}_2\times\mathbb{Z}_4$）。

## ★ 3. 环与域（6.5 重点，6.5.2 不考）

### 定义链

环 = 加法阿贝尔群 + 乘法半群 + 分配律
→ **整区**（交换 + $1\ne0$ + 无零因子）
→ **体**（$1\ne0$ + 非零元可逆）
→ **域**（交换体）

### 六个必背结论

| 结论 | 说明 |
| --- | --- |
| 零因子个数 | $=n-\varphi(n)-1$（$\mathbb{Z}_{12}$：$12-4-1=7$） |
| 有限整区 ⇒ 域 | **单向**。域不必有限 |
| 消去环中加法周期 | **只能是素数**，且整除 $\lvert R\rvert$ |
| 整区中幂等元 | **恰好 2 个**：$0,1$ |
| 子环含壹 | $\lvert N\rvert$ **整除** $\lvert R\rvert$（用**加法群** + 拉格朗日） |
| 两个不同壹 $e,e'$ | $e'(e'-e)=0$ ⇒ 有零因子 ⇒ **不是消去环** |

> [!warning] 一条最容易被绕进去的
> "没有零因子的环一定是整区"——**错**。还缺**交换**和**含 $1$**。
> 反例：$2\mathbb{Z}$（无零因子、无 $1$）、四元数体 $\mathbb{H}$（无零因子、非交换）。

## ★ 4. 格与布尔代数

### 一条线

偏序集 →（任意两元素有确界）→ **格** →（+$0,1$）**有界格** →（+余元素）**有余格** →（+分配）**布尔代数**

### 判定固定顺序

**第一步：是不是格？** 只看一句——**任意两个元素在集合内有没有确界**。

> 判"最小上界"：**把所有上界列出来，问"有没有一个能整除其余全部"**。
> 有 → 它就是；没有 → **最小上界不存在**。
> 注意：**比的是整除，不是数值大小。**

**第二步：分不分配？**

| 路 | 做法 |
| --- | --- |
| 看形状（快） | 找 $M_3$（中间**并排三个**）或 $N_5$（**一条链旁挂一个点**）。找到 ⇒ 不分配 |
| 验封闭（稳） | 对 $\gcd$ **和** $\operatorname{lcm}$ **都封闭** ⇒ 一定分配 |

> **"是格"不保证分配，"封闭"才保证。**
> 反例 $\{1,2,3,4,12\}$：是格，但 $4\wedge(2\vee3)=4$，$(4\wedge2)\vee(4\wedge3)=2$ ⇒ 不分配。

**第三步：有没有余？** **别数形状，直接拿最大元素去试。**

> $D(12)$ 中 $6$ 要 $\gcd(6,x)=1$ 且 $\operatorname{lcm}(6,x)=12$。
> $\gcd(6,x)=1$ ⇒ $x\in\{1,5\}$，$5\notin D(12)$；$x=1$ 时 $\operatorname{lcm}=6\ne12$。
> **矛盾 ⇒ 6 无余元素 ⇒ $D(12)$ 不是有余格 ⇒ 不是布尔代数。**

### 五格对照（必默）

| 格 | 元素 | 分配 | 有余 |
| --- | --- | --- | --- |
| 链 $C_3$：$0<a<1$ | 3 | ✅ | ❌（$a$ 无余） |
| 链 $C_4$：$0<a<b<1$ | 4 | ✅ | ❌ |
| 钻石 $B_2$：$0<a,b<1$ | 4 | ✅ | ✅ |
| 钻石 $M_3$：$0<a,b,c<1$ | 5 | ❌ | ✅（**余不唯一**） |
| 五角 $N_5$：$0<a<b<1$，$c$ 旁挂 | 5 | ❌ | ✅ |

> **4 元格同构下只有两种（$C_4$、$B_2$），都分配；$C_4$ 不有余。**
> 速记：链一定分配；**元数 $<5$ 的格一定分配**；布尔代数一定分配。

### 子格 vs 子代数（判断题必考）

| | 要求 |
| --- | --- |
| **子格** | 对 $\wedge$、$\vee$ 封闭 |
| **子代数** | 对 $\wedge$、$\vee$、$\bar{\ }$ **三种**都封闭，**且含 $0$ 和 $1$** |

> **子代数更强**：子代数一定子格，子格不一定是子代数。
> **造"子格非子代数"的万能模板：链。** 链天生对交并封闭，但余元素会把元素"翻到另一头"，几乎必然出界。
> 例：$S=\{\varnothing,\{a\},\{a,b\},\{a,b,c\}\}$ 是链 ⇒ 子格；但 $\{a\}$ 的余元素 $\{b,c\}\notin S$ ⇒ 不是子代数。

### 亨廷顿四组公理（闭卷默写）

| | 公理 |
| --- | --- |
| **H1 交换** | $a\cdot b=b\cdot a$，$a+b=b+a$ |
| **H2 分配** | $a\cdot(b+c)=(a\cdot b)+(a\cdot c)$，$a+(b\cdot c)=(a+b)\cdot(a+c)$（**两向都要**） |
| **H3 同一** | 存在 $0,1$：$a\cdot1=a$，$a+0=a$ |
| **H4 互补** | $a+\bar a=1$，$a\cdot\bar a=0$ |

> 前提：$B$ **至少两个元素**。余元素写 $\bar a$，**不叫"补元"、不写 $a^{-1}$**。

## ★ 5. 五个证明模板（照抄，不用灵感）

### ① 拉格朗日：$\lvert G\rvert=\lvert H\rvert\cdot[G:H]$

> **一、每个左陪集与 $H$ 等势.** 定义 $\varphi:H\to aH$，$\varphi(h)=ah$。
> 满射：$aH=\{ah\mid h\in H\}$，每个元素都形如 $ah$（**把定义抄一遍**）。
> 单射：若 $ah_1=ah_2$，左消去得 $h_1=h_2$。
> 故 $\lvert aH\rvert=\lvert H\rvert$。
> **二、不同左陪集互不相交.** 设 $aH\cap bH\ne\varnothing$，取 $x=ah_1=bh_2$，则 $a=bh_2h_1^{-1}\in bH$，故 $aH\subseteq bH$；对称得 $bH\subseteq aH$，故 $aH=bH$。
> **三、数数.** 左陪集构成划分，共 $[G:H]$ 个，每个元数 $=\lvert H\rvert$，故 $\lvert G\rvert=\lvert H\rvert\cdot[G:H]$。$\blacksquare$

> [!tip] 单射管"不重复"，满射管"不漏"，**两个都写才有一一对应**。
> 只写单射要扣分——不重复 ≠ 一样多。

### ② 第三同态定理（6.4.4）：$G/N\cong\sigma(G)$

构造 $\Phi:G/N\to\sigma(G)$，$\Phi(aN)=\sigma(a)$。

| 步 | 写什么 |
| --- | --- |
| ① **良定义** | $aN=bN$ ⇒ $b^{-1}a\in N=\sigma^{-1}(1')$ ⇒ $\sigma(b^{-1}a)=1'$ ⇒ $\sigma(a)=\sigma(b)$ |
| ② **同态** | $\Phi(aNbN)=\Phi(abN)=\sigma(ab)=\sigma(a)\sigma(b)$ |
| ③ **单射** | $\Phi(aN)=1'$ ⇒ $\sigma(a)=1'$ ⇒ $a\in N$ ⇒ $aN=N$ |
| ④ **满射** | 任取 $y\in\sigma(G)$，存在 $a$ 使 $\sigma(a)=y$ |

> **良定义不能省**——$aN$ 有多个代表元。这是最容易扣分的一步。
> 四个空里有三个是**抄 $N$ 的定义**。

### ③ $N\triangleleft G$ + 单射判据

> **正规**：任取 $g\in G,k\in N$，$\sigma(gkg^{-1})=\sigma(g)\sigma(k)\sigma(g)^{-1}=\sigma(g)1'\sigma(g)^{-1}=1'$，故 $gkg^{-1}\in N$。
> **单射 $\iff N=\{1\}$**：
> **⇒** 若 $\sigma(a)=\sigma(b)$，则 $\sigma(ab^{-1})=1'$，$ab^{-1}\in N=\{1\}$，故 $a=b$。
> **⇐** 若 $N\ne\{1\}$，取 $x\ne1$ 在核中，则 $\sigma(x)=1'=\sigma(1)$ 但 $x\ne1$，不是单射。

### ④ 余元素唯一（有余分配格）

> 设 $b,c$ 都是 $a$ 的余元素，则 $a\wedge b=0,a\vee b=1$，对 $c$ 同理。
> $$b=b\wedge1=b\wedge(a\vee c)=(b\wedge a)\vee(b\wedge c)=0\vee(b\wedge c)=b\wedge c$$
> 对称地 $c=c\wedge b=b\wedge c$，故 $b=c$。$\blacksquare$

> **"唯一"的标准动作：假设两个，证相等。**

### ⑤ 有限整区是域（PPT P36 五步）

记 $R^*=R\setminus\{0\}$，证 $R^*$ 是乘法群：
$1\in R^*$；无零因子 ⇒ 封闭；结合律继承；单位元 $1$；
任取 $a\ne0$：消去律 ⇒ $x\mapsto ax$ **单射** ⇒ $R^*$ **有限** ⇒ **单射即满射** ⇒ $aR^*=R^*$ ⇒ 存在 $k$ 使 $ak=1$。
故 $R^*$ 是群 ⇒ 体；整区交换 ⇒ 域。$\blacksquare$

> **凡证明里出现"有限"，就要出现"单射即满射"五个字。**

### ⑥ $H\cap K\le G$（11/14 模拟卷证明 1）

> ① 非空：$1\in H$，$1\in K$ ⇒ $1\in H\cap K$。
> ② 任取 $a,b\in H\cap K$：$a,b\in H$ 且 $H\le G$ ⇒ $ab^{-1}\in H$；同理 $ab^{-1}\in K$。故 $ab^{-1}\in H\cap K$。
> ③ 由子群判别法，$H\cap K\le G$。$\blacksquare$
>
> **反例（$H\cup K$ 不是子群）**：$G=\mathbb{Z}_6$，$H=\{0,2,4\}$，$K=\{0,3\}$，$2+3=5\notin H\cup K$。

> [!danger] 反例里的 $G$ 必须先是群
> 幂集配 $\cup$ **不是群**。要用幂集造这个反例，运算必须换成**对称差 $\Delta$**：$(\mathcal{P}(S),\Delta)$ 才是群。

## ★ 9. 纵向链条（升级轴：加条件，越走越强）

> 一句话：**纵向是「加条件」，横向是「换角度」。**

### 9.0 循环群与交换群的位置（11/14 你记反过，这条最要紧）

```
        群
         │  +交换律
         ▼
     交换群（Abel 群）
         │  +「一个生成元就够」
         ▼
      循环群            ← 最强、最窄
```

> **只往下推，不能往上推：**
> $$\text{循环群}\ \Longrightarrow\ \text{交换群}\ \Longrightarrow\ \text{群}$$

| 方向 | 成立？ | 反例 |
| --- | --- | --- |
| 循环 ⇒ 交换 | ✅ 永远成立 | — |
| 交换 ⇒ 循环 | ❌ | $V_4=\mathbb{Z}_2\times\mathbb{Z}_2$：交换，但每个非零元周期都是 2，**不循环** |
| 群 ⇒ 交换 | ❌ | $S_3$ |

> [!danger] 你 11/14 的原话（错的）
> 「具备生成元，然后变成循环群，再变成交换群」——**方向倒过来了**。
> 正确：**交换群是循环群的「上一层」（更宽），不是下一层。**
> 另一句错的：「阿贝尔群是循环群」——**反了**。循环群才是 Abel 群。

> [!tip] 三个「必循环」的快速判据
> 1. **元数为质数** ⇒ 必循环（6.3 P85）⇒ 必交换
> 2. **元数为 1、2** ⇒ 既 Abel 又循环
> 3. **$\mathbb{Z}_n$（加法）** ⇒ 永远循环

### 9.1 代数系统这条（第 6 章）

```
半群 ──+单位元──▶ 幺半群 ──+逆元──▶ 群 ──+交换──▶ Abel 群 ──+一个生成元──▶ 循环群

环 = 加法 Abel 群 + 乘法半群 + 分配律
整区 = 交换环 + 含 1(1≠0) + 无零因子
体   = 含 1(1≠0) + 非零元对乘法成群
域   = 交换体
```

| 升级 | 加了什么 | 反例（证明「不加就不够」） |
| --- | --- | --- |
| 半群 → 幺半群 | 单位元 | $(\mathbb{Z}^+,+)$ |
| 幺半群 → 群 | 逆元 | $(\mathbb{Z},\times)$（$0$ 无逆） |
| 群 → Abel 群 | 交换律 | $S_3$ |
| **Abel → 循环** | **一个生成元就够** | $V_4=\mathbb{Z}_2\times\mathbb{Z}_2$ |
| 环 → 整区 | 交换 **+** 含 $1\ne0$ **+** 无零因子 | $2\mathbb{Z}$（无 $1$）／$\mathbb{Z}_6$（有零因子）／$\mathbb{H}$（非交换） |
| 整区 → 域 | 非零元可逆 | $\mathbb{Z}$（$2$ 无逆） |
| 体 → 域 | 交换律 | 四元数体 $\mathbb{H}$ |

> [!danger] 另一条最容易记反的单向箭头
> **有限整区 ⇒ 域，但域 ⇏ 有限**（$\mathbb{Q},\mathbb{R},\mathbb{C}$ 都是域且无限）。

### 9.2 格这条（第 7 章）

```
偏序集 ──+任意两元素有确界──▶ 格 ──+最小元0最大元1──▶ 有界格
                                    ──+每个元素有余元素──▶ 有余格
                                    ──+分配律且 0≠1──▶ 布尔代数
```

| 升级 | 加了什么 | 反例 |
| --- | --- | --- |
| 偏序集 → 格 | **任意两个**元素有确界 | $\{0,a,b,x,y,1\}$：$a,b$ 的上界 $x,y$ 不可比 ⇒ 无最小上界 |
| 格 → 有界格 | 最小元 $0$、最大元 $1$ | 无限链 $(\mathbb{Z},\le)$ 无界 |
| 有界格 → 有余格 | 每个元素有余元素 | $C_3$：$a$ 无余元素；$D(12)$：$6$ 无余元素 |
| 有余格 → 布尔代数 | 分配律 **+** $0\ne1$ | $M_3$：有余但**非分配** |

> [!danger] 两个「加了也不够」
> 1. **有界 ⇏ 格**：有界只说整体有顶有底，格要**每对**有确界。
> 2. **有余 ⇏ 分配**（$M_3$），**分配 ⇏ 有余**（$C_3$）。**互不包含。**

## ★ 10. 横向链条（结构轴：换角度看同一个群）

> **整个 6.3–6.4 只做一件事：把大群「折叠」成小群。**
> 三个工具，一个比一个强：**取子群 → 取陪集 → 取商群/同态**。

### 10.1 12 级脊柱（一条线串完 24 个概念）

```
【元素级】
 ① 元素 a
       │ 反复自乘，看何时回到 1
       ▼
 ② a 的周期 n  ═══════ |⟨a⟩|        ★ 周期(a) = |⟨a⟩|
       │ 生成
       ▼
【子结构级】
 ③ 循环子群 ⟨a⟩ ── 一定是子群
       │ 去掉「循环」限制
       ▼
 ④ 子群 H ── 判别条件一/二/三（三只对有限）
       │ 拿 H 平移整个群
       ▼
【分割级】
 ⑤ 陪集 aH ── 七条性质；|aH|=|H|
       │ 数几块
       ▼
 ⑥ 指数 [G:H] = |G|/|H|  ═════ 拉格朗日 |G|=|H|·[G:H]
       │ 块能不能自己成群？
       ▼
 ⑦ 正规子群 N ── aN = Na
       │ 每块压成一个点
       ▼
 ⑧ 商群 G/N ── 元数 = [G:N]
       │
       ▼
【映射级】
 ⑨ 同态 σ : G → G′
       │ 哪一块被压成 1′？
       ▼
 ⑩ 核 N = σ⁻¹(1′) ── 一定是正规子群
       │ 守恒：|G| = |N| × |G′|
       ▼
 ⑪ 同构 G′ ≅ G/N ── 第三同态定理
       │
       ▼
 ⑫ 自同构（G′ = G）
```

> **做题先问：这题停在第几级？**
> 问周期/生成元 → ②；问几个子群 → ④；问指数/陪集 → ⑥；问正不正规 → ⑦；问商群元数 → ⑧；问核/同态 → ⑩；问同构 → ⑪。

### 10.2 两个守恒律（考场上直接除）

$$\lvert G\rvert=\lvert H\rvert\cdot[G:H]\qquad\lvert G\rvert=\lvert N\rvert\cdot\lvert G'\rvert$$

> 给 $\lvert G\rvert$ 和 $\lvert N\rvert$ 问 $\lvert G'\rvert$ → **直接除**。
> 验算：$\lvert G\rvert=6$，$\lvert N\rvert=3$，则 $\lvert G'\rvert=2$。

### 10.3 组间接口：只记「两必然 + 一必须」

| | 接口 | 依据 |
| --- | --- | --- |
| **必然** | $A_n$ 一定正规（指数 2） | 6.3 P94 |
| **必然** | 同态的核一定正规 | 6.4 P24 |
| **必须** | 做商群**必须**用正规子群 | 6.4 P31 |

其余接口都是「定义直接推」：
- 周期(a) = $\lvert\langle a\rangle\rvert$；$\langle a\rangle$ 一定是子群
- **Abel 群的任意子群都正规**
- 正规 $\iff$ $\forall a:\ aH=Ha$
- 自然同态 $\pi:a\mapsto aN$ 的核**恰好**是 $N$
- 子群的像仍是子群；**正规的像仍正规**

### 10.4 最容易混的五对（你都错过或差点错）

| 对 | 一句话区别 | 反例 / 判据 |
| --- | --- | --- |
| **子群 vs 陪集** | 子群是**群**，陪集一般**只是集合** | 只有含 $I$ 的那块是子群；$H$ 的陪集里**恰好 1 个**是子群 |
| **元数 vs 周期** | 元数描述**群**，周期描述**元素** | $\lvert\langle a\rangle\rvert=$ 周期$(a)$ |
| **指数 vs 元数** | 指数是**块数**，元数是**块里元素数** | $\lvert G\rvert=\lvert H\rvert\times[G:H]$ |
| **核 vs 像** | 核在**定义域**一侧，像在**陪域**一侧 | $\mathbb{Z}_{18}\to\mathbb{Z}_6$ 的核是 $\{0,6,12\}$，**不是** $\{0,1,\dots,5\}$ |
| **同态 vs 同构** | 同构 = 同态 + **双射** | **同态会压缩，同构不会** |

### 10.5 同态保什么、不保什么

| 保 | 不保（反例） |
| --- | --- |
| 单位元 $1'=\sigma(1)$、逆元、幂 $\sigma(a^k)=\sigma(a)^k$ | **单射**：$\mathbb{Z}\to\mathbb{Z}_3$ |
| 子群 → 子群；**正规 → 正规** | **满射**：$\mathbb{Z}\to\mathbb{Z}$，$x\mapsto2x$ |
| 循环 → 循环（需满射） | **周期/元数**：$\mathbb{Z}\to\mathbb{Z}_3$，$1$ 的周期 $\infty\to3$ |
| | **子群个数**：同上 |

> **同构保周期**：$a^k=1\iff\sigma(a)^k=1'$。所以 $\mathbb{R}^*\not\cong\mathbb{R}$（$\mathbb{R}^*$ 有 2 周期元 $-1$，$\mathbb{R}$ 没有）。

### 10.6 置换那条旁支（终点接回主链 ⑪）

```
置换 → 不相杂轮换（可交换）→ 拆成对换 → 奇/偶置换（各 n!/2）
     → Aₙ（指数 2 ⇒ 正规）→ Sₙ/Aₙ ≅ ℤ₂（符号同态，核 = Aₙ）
```

> **置换周期** = 不相杂轮换长度的 $\operatorname{lcm}$；**奇偶** = $n-k$（$k$ 含单轮换）。

### 10.7 横向上的四条硬结论（都错过）

| 结论 | 反例 / 说明 |
| --- | --- |
| **拉格朗日不可逆**：因数 $m$ 未必有 $m$ 元子群 | $A_4$（12 元）**没有 6 元子群** |
| **「因数 ⇒ 唯一子群」只对循环群** | $S_3$ 的 2 元子群有 **3 个** |
| **指数 2 ⇒ 正规，但指数 3 不行** | $S_3$ 中 $\{I,(1\,2)\}$ 指数 3，**不正规** |
| **子代数 ⇒ 子格，反之不成立** | 链 $\{\varnothing,\{a\},\{a,b\},\{a,b,c\}\}$ 是子格，非子代数（余元素出界） |

> [!tip] 无限循环群
> $\mathbb{Z}=\langle1\rangle$ 是循环群（每个整数都是 1 的倍数）。**「循环」= 一个生成元就够，跟绕不绕回来无关。**
> 无限循环群生成元**恰好 2 个**：$a$ 与 $a^{-1}$。
