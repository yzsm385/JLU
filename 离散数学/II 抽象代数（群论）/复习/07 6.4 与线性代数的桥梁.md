# 6.4 与线性代数的桥梁

> [!tip] 为什么要写这一页
> 同态、核、商群、正规子群这一串词看起来全新，其实**你已经在线性代数里学过一遍**。
> 把 6.4 翻译成「线性映射的语言」，记忆量立刻减半。

## 一、词源澄清：两个「合同」不是一回事

| 词 | 出处 | 含义 | 英文 |
| --- | --- | --- | --- |
| 群的**合同关系** | 高斯「同余」 | 与运算相容的**等价关系** | congruence **relation** |
| 矩阵的**合同变换** | 二次型 | $A\mapsto P^{\mathsf T}AP$ | congruence **of matrices** |

教材「$a=bh$ → 右模 $H$ 的合同关系」说的是**同余**（类似 $a\equiv b\pmod n$），与 $P^{\mathsf T}AP$ 无关。

## 二、$gng^{-1}$ 对应「相似」，不是「合同」

| 线性代数 | 群论 | 保什么 |
| --- | --- | --- |
| **相似** $A\mapsto P^{-1}AP$ | **共轭** $x\mapsto gxg^{-1}$ | 换基不变的本质 |
| **合同** $A\mapsto P^{\mathsf T}AP$ | **无对应** | 二次型惯性指数 |

矩阵合同需要**转置**（依赖对偶空间），群只有一个运算、没有对偶，所以定义不出转置。$gng^{-1}$ 只能是相似那一支。

**正规子群的准确直觉**：共轭不变 = 换坐标不变 = 不依赖代表元的选择，所以 $G/N$ 才能良定义。

## 三、核心对照表

| 线性代数 | 群论 |
| --- | --- |
| 线性映射 $T(av+bw)=aT(v)+bT(w)$ | 同态 $\sigma(ab)=\sigma(a)\sigma(b)$ |
| 零空间 $\ker T$ | 核 $\ker\sigma=\sigma^{-1}(e')$ |
| 像 $\operatorname{Im}T$ | 像 $\sigma(G)$ |
| 商空间 $V/W$ | 商群 $G/N$ |
| **$V/\ker T\cong\operatorname{Im}T$** | **$G/\ker\sigma\cong\operatorname{Im}\sigma$** |
| $\dim V=\dim\ker T+\dim\operatorname{Im}T$ | $\lvert G\rvert=\lvert N\rvert\cdot[G:N]$ |
| 单射 $\iff\ker T=\{0\}$ | 单射 $\iff\ker\sigma=\{e\}$ |
| 线性映射的矩阵表示 | 同态的具体公式（如 $x\mapsto x\bmod n$） |

## 四、为什么线代没有「正规子群」

向量空间的加法**交换**，交换群的所有子群都正规，所以 $V/W$ 永远良定义，永远不用检查。

> **「正规」是「运算不交换」逼出来的概念。**

这也解释了「商群为什么必须正规」：$aN\cdot bN=abN$ 的良定义中间要 $Nb=bN$。交换群里这步自动成立，所以线代里从没意识到有这一步。

## 五、正交变换的位置（为什么两个词容易混）

$Q$ 正交时 $Q^{\mathsf T}=Q^{-1}$，故 $Q^{\mathsf T}AQ=Q^{-1}AQ$：**正交变换使合同与相似重合**，这就是「相似与合同的交集是正交变换」。

但它只是**词容易混的原因**，不是群论的骨架。$O(n)$ 在群论里只是「一个具体的群」，是例子。

## 六、五条记忆锚点

1. 同态 = 保持运算 = 线性映射的群版本。
2. 核 = 零空间 = 被压成单位元的那一叠。
3. 商群 = 商空间。
4. 基本定理 = $V/\ker T\cong\operatorname{Im}T$，一字不差。
5. 正规 = 共轭不变 = 换基不变 = $G/N$ 能定义的前提。

## 七、待验证的疑问（考完再想）

- 正规子群 ↔ 泛代数里的「同余关系」：群上的同余关系与正规子群一一对应。教材用「合同关系」这个词其实有深意，指的是这个方向，而不是矩阵合同。
- 内自同构 $\sigma_a(x)=axa^{-1}$ 全体构成群 $\operatorname{Inn}(G)$，对应线代里「所有换基操作」的集合。
