## ★ 0. 三张必会图

**① $M_3$（钻石格）**：$0<a,b,c<1$，$a,b,c$ 两两不可比。**非分配格**（余元素不唯一）。
反例：$a\vee(b\wedge c)=a$，而 $(a\vee b)\wedge(a\vee c)=1$。

**② $N_5$（五角格）**：$0<a<b<1$，$c$ 与 $a,b$ 不可比。**非模，非分配**。
反例：$b\wedge(c\vee a)=b$，而 $(b\wedge c)\vee a=a$。

**③ 同态基本定理**：$\sigma:G\to G'$ 满同态，核 $N=\sigma^{-1}(1')$，则 $N\triangleleft G$，且

$$G/N\;\cong\;\sigma(G).$$

> [!warning] 记号按 PPT 写，不写 $\ker$ / $\operatorname{Im}$
> PPT 全程用 **$N=\sigma^{-1}(1')$**（6.4 P23–P28）和 **$\sigma(G)$**（6.4 P7）。
> 线性代数里的 $\ker T$、$\operatorname{Im}T$ 不要搬到群论卷面上。

> ★ 证明四行（4 个验证点，缺一个扣分）：构造 $\varphi(aN)=\sigma(a)$，
> ① 良定义 $aN=bN\Rightarrow a^{-1}b\in N\Rightarrow\sigma(a)=\sigma(b)$；
> ② 同态 $\varphi(aNbN)=\sigma(ab)=\sigma(a)\sigma(b)$；
> ③ 单射 $\sigma(a)=1'\Rightarrow a\in N\Rightarrow aN=N$；
> ④ 满射 $G'=\sigma(G)$。

# 第 6 章 · 群、环、域

## 一、定义链（一条线背下来）

代数系统 → 半群（+结合）→ 幺半群（+单位元）→ 群（+逆元）→ 阿贝尔群（+交换）→ 循环群（+一个生成元）

环 = 加法阿贝尔群 + 乘法半群 + 分配律 → 整区（交换 + $1\ne0$ + 无零因子）→ 体（$1\ne0$ + 非零元可逆）→ 域（交换体）

## 二、默写级定义

| 概念 | 一句话 | 易错 |
| --- | --- | --- |
| 群 | 非空集合 + 二元运算，满足封闭、结合、有 $e$、有逆 | 五步缺一不可 |
| 子群 | $H\subseteq G$ 非空，对 $G$ 的**同一运算**构成群 | 不能只说「子集」 |
| 正规子群 | $\forall g\in G,\ gH=Hg$ | 是集合相等，不是 $gh=hg$ |
| 同态 | $\varphi(ab)=\varphi(a)\varphi(b)$ | 不要求双射 |
| 核 | $N=\sigma^{-1}(1')=\{x\in G\mid\sigma(x)=1'\}$ | 必是正规子群；**不写 $\ker$** |
| 环 | $(R,+)$ 阿贝尔群，$(R,\cdot)$ 半群，分配律 | 乘法**不是**群 |
| 整区 | 交换环 + 含 $1\ne0$ + 无零因子 | 缺一不可 |
| 体 | 含 $1\ne0$，非零元对乘法成群 | 不要求交换 |
| 域 | 交换体 | 要求交换 |

## 三、必背定理（条件 → 结论）

| 定理 | 条件 | 结论 |
| --- | --- | --- |
| 群性质 1 | 群 | $e$ 唯一、$a^{-1}$ 唯一；$(ab)^{-1}=b^{-1}a^{-1}$ |
| 群性质 2 | 左单位元 + **左**逆（同侧） | 已是群（异侧不行） |
| 群性质 3 | 半群 + 可除；或有限半群 + 消去 | 是群 |
| 子群判别 | $H\ne\varnothing$，$a,b\in H\Rightarrow ab^{-1}\in H$ | $H\le G$ |
| 有限子群判别 | $G$ 有限，$H\ne\varnothing$ 且对乘法封闭 | $H\le G$ |
| 拉格朗日 | $H\le G$，$G$ 有限 | $\lvert G\rvert=[G:H]\cdot\lvert H\rvert$；$\lvert a\rvert\mid\lvert G\rvert$ |
| 指数 2 | $[G:H]=2$ | $H\triangleleft G$ |
| 循环群 | $G=\langle a\rangle$，$\lvert a\rvert=n$ | $G\cong\mathbb{Z}_n$；生成元 $\varphi(n)$ 个 |
| 同态基本定理 | $\sigma:G\to G'$ 满同态，核 $N=\sigma^{-1}(1')$ | $G/N\cong\sigma(G)$（**不写 $\ker$、$\operatorname{Im}$**） |
| 单同态判据 | $\sigma$ 同态 | $\sigma$ 单射 $\iff\sigma^{-1}(1')=\{1\}$ |
| 定理 6.4.2 | $\sigma$ 满同态，$N=\sigma^{-1}(1')$ | $\sigma^{-1}(a')$ 是 $N$ 的陪集；$G'$ 元素 ↔ $G/N$ 元素一一对应 |
| 定理 6.4.3 | $N\trianglelefteq G$ | $G/N$ 成群；$\tau:a\mapsto aN$ 满同态，核 $=N$ |
| 有限整区 | $R$ 为有限整区 | $R$ 是域 |

## 四、公式

- $\lvert a^m\rvert=\dfrac{n}{\gcd(n,m)}$（$\lvert a\rvert=n$）
- $\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right)$
- 置换奇偶：$n-k$，$k$ 为不相杂轮换个数（**含单轮换**）；$n-k$ 为奇 ⇒ 奇置换
- $\lvert A_n\rvert=n!/2$
- $[G:H]=\lvert G\rvert/\lvert H\rvert$
- **周期 = 不相杂轮换长度的 $\operatorname{lcm}$**；$\lvert\langle\sigma\rangle\rvert=$ 周期
- **求 $\sigma^k$**：先算周期 $m$，再取 $r=k\bmod m$，答案 $=\sigma^r$（$r=0$ 时是 $I$）

## ★ 四之二、三个必须分清的数（第三次犯了，考前最后一遍）

| 名词 | 是什么 | 例：$\mathbb{Z}_{18}$ 中 $\langle6\rangle=\{0,6,12\}$ |
| --- | --- | --- |
| **元数** | 群/子群里**元素的个数** | $3$ |
| **周期** | **单个元素**的周期 $=$ $\lvert\langle a\rangle\rvert$ | $6$ 的周期是 $3$ |
| **指数** | **陪集的个数** $=\lvert G\rvert/\lvert H\rvert$ | $18/3=6$ |

> 元数描述**群**，周期描述**元素**，指数描述**子群在群里占几摞**。
> 桥梁：**周期$(a)=\lvert\langle a\rangle\rvert$**（PPT 6.3 P41）。

## ★ 四之三、循环群速查

| 问 | 答 |
| --- | --- |
| $n$ 元循环群 $\mathbb{Z}_n$ 有几个子群 | $n$ 的正因数个数（与因数**一一对应**） |
| $d\mid n$，$d$ 元子群有几个 | **恰好 1 个**（$=\langle n/d\rangle$） |
| $n$ 元循环群生成元个数 | $\varphi(n)$，具体是 $a^k$ 且 $(k,n)=1$ |
| $\mathbb{Z}_n^*$ 循环吗 | $\iff n=1,2,4,p^k,2p^k$（$p$ 奇素数） |
| 非循环时生成元个数 | **0** |

> **$\mathbb{Z}_{20}^*$ 是坑**：$20=4\cdot5$，不在列表 ⇒ 非循环（$\cong\mathbb{Z}_2\times\mathbb{Z}_4$），生成元 **0 个**。
> $\mathbb{Z}_{16}^*,\mathbb{Z}_8^*,\mathbb{Z}_{12}^*$ 也都**非循环**。

## 五、反例库（判断说明题直接用）

| 反例 | 说明 |
| --- | --- |
| $(\mathbb{Z},\times)$ | 幺半群非群（$0$ 无逆） |
| $(\mathbb{Z}^+,+)$ | 半群非幺半群 |
| $S_3$ | 非阿贝尔；指数 3 的子群不正规 |
| $\mathbb{Z}_6$ 中 $\{0,2,4\}\cup\{0,3\}$ | 两个子群之并不一定是子群 |
| $2\mathbb{Z}$ | 无零因子但非整区（无 $1$） |
| $\mathbb{Z}$ | 整区非域 |
| $\mathbb{Z}_6$ | 有零因子，非整区 |
| 四元数体 $\mathbb{H}$ | 体非域 |
| 三元素链 $0<a<1$ | 有界、分配，但非有余 |
| $M_3$ | 有余、模，但非分配 |
| $N_5$ | 非模，非分配 |
| $D(12)$ | 有界、分配，但非有余（$6$ 无余元素） |

# 第 7 章 · 格与布尔代数

## 六、一条线

偏序集 →（任意两元素有确界）→ 格 →（+0,1）有界格 →（+余元素）有余格 →（+分配）布尔代数

## 七、默写级定义

| 概念 | 一句话 | 易错 |
| --- | --- | --- |
| 偏序 | 自反、反对称、传递 | 不要求任意两元素可比 |
| 确界 | 最小上界 / 最大下界 | 不是「最大元」 |
| 格 | 任意**两个**元素都有 $\inf$ 和 $\sup$ | 不是任意子集 |
| 代数格 | 交换、结合、吸收 | 吸收律推出幂等律 |
| 子格 | 非空子集，对 $\wedge,\vee$ 封闭 | 确界要在子集内取到 |
| 有界格 | 有最小元 0、最大元 1 | 有界 ≠ 有限 |
| 有余格 | 每个元素有余元素 | 余元素不一定唯一 |
| 分配格 | $a\vee(b\wedge c)=(a\vee b)\wedge(a\vee c)$ | 一般格只有 $\le$ |
| 布尔代数 | 有界 + 有余 + 分配，且 $0\ne1$ | 别漏 $0\ne1$ |
| 子代数 | 对 $\wedge,\vee$ 与补运算封闭，含 0/1 | 比子格多「补封闭」 |

## 八、格的核心结论

- 两种定义等价：$a\le b\iff a\wedge b=a\iff a\vee b=b$
- 对偶原理：**PPT 标注删除**，只需知道「格的命题成对出现」（$\le\leftrightarrow\ge$、$\wedge\leftrightarrow\vee$、$0\leftrightarrow1$）
- 分配不等式：$a\vee(b\wedge c)\le(a\vee b)\wedge(a\vee c)$
- 分配格 $\iff$ 不含 $M_3$、$N_5$ 作子格
- 模律：$a\le b\Rightarrow a\vee(c\wedge b)=(a\vee c)\wedge b$（**不考**）
- 有界分配格中**余元素唯一**；布尔代数中 $\bar a$ 唯一
- 布尔代数：De Morgan、$a\le b\iff a\wedge b'=0$、$a\vee(a'\wedge b)=a\vee b$
- 格同态保 $\wedge,\vee$；**保序 ≠ 同态**（反例：$\mathcal{P}(\{1,2\})\to\{0<c<1\}$，$f(\{1\})=f(\{2\})=c$，但 $f(\{1\}\wedge\{2\})=0\ne c$）

## ★ 八之一、判定「是不是格 / 分不分配」的固定顺序（11/13 修正）

**第一步：是不是格？** 只看一句——**任意两个元素在集合内有没有确界**。

> 判「最小上界」的动作：**把所有上界列出来，问「这里面有没有一个元素能整除其余全部」**。
> - 有 → 它就是最小上界（**其余上界彼此不必可比**）
> - 没有 → **最小上界不存在**

**24 题**：$L=\{1,2,3,12,18,36,72\}$，$2,3$ 的上界是 $\{12,18,36,72\}$。$12\nmid18$、$18\nmid12$，**一个都当不了** ⇒ 不是格。
（官方理由：$\gcd(12,18)=6\notin L$，从下界方向断，同一个病。）

> [!danger] 三个高频误判
> ① **「12 比 18 小所以 12 是最小上界」** —— 错。这里比的是**整除**，不是数值大小。
> ② **$\operatorname{lcm}(a,b)\notin S$ 就直接判「不是格」** —— 不严谨。$\{1,2,3,12\}$ 中 $\operatorname{lcm}(2,3)=6\notin S$，但 $2\vee3=12$ 存在，**它是格**。
> ③ **「整除集是格就一定分配」** —— **错**。反例 $\{1,2,3,4,12\}$ 是格但不分配。

**第二步：分不分配？** 两条路，任选：

| 路 | 做法 |
| --- | --- |
| **看形状**（快） | 找 $M_3$（中间**并排三个**两两不可比、上下各一个）或 $N_5$（**一条链旁边挂一个点**）。找到 ⇒ 不分配 |
| **验封闭**（稳） | 集合对 $\gcd$ **和** $\operatorname{lcm}$ **都封闭** ⇒ 是 $(\mathbb{N}^+,|)$ 的子格 ⇒ **一定分配** |

> **「封闭」才保证分配，「是格」不保证。** 差别就在「确界有没有被抬高」：
> $\{1,2,3,4,12\}$ 里 $2\vee3$ 被迫抬到 $12$（6 不在），于是 $4\wedge(2\vee3)=4$，而 $(4\wedge2)\vee(4\wedge3)=2$，**分配律断**。

**速记**：链一定分配；**元数 $<5$ 的格一定分配**（装不下 $M_3/N_5$，都要 5 个点）；布尔代数一定分配。

**质因数指数向量表**（比画图可靠）：$600=(3,1,2)$、$75=(0,1,2)$、$25=(0,0,2)$、$8=(3,0,0)$。
整除 $=$ **逐分量 ≤**，$\gcd=$ 逐分量 min，$\operatorname{lcm}=$ 逐分量 max。
32 题 $2=(1,0,0)$、$3=(0,1,0)$ 的 lcm 是 $(1,1,0)=6$，表里没有 ⇒ 直接出局。

**32 题的正确理由**：$S=\{1,2,3,4,5,8,25,75,600\}$ **是格**，但含 **$N_5$ 型子格** $\{1,3,5,25,75\}$：
链 $1<5<25<75$，$3$ 与 $5,25$ 都不可比，且 $3\wedge5=3\wedge25=1$、$3\vee5=3\vee25=75$ ⇒ **不分配**。

**数子格的口诀**：**先报总数 $C(n,3)$，再减「同时含不可比那一对」的个数。**
27 题：$C(5,3)=10$，唯一不可比的对是 $(c,d)$，含它的有 3 个 ⇒ $10-3=7$。
可比的对永远安全（交并就是它们自己），**只有不可比的对会跑出去**。

## ★ 八之二、亨廷顿四组公理（闭卷默写）

| | 公理 |
| --- | --- |
| H1 交换 | $a\cdot b=b\cdot a$，$a+b=b+a$ |
| H2 分配 | $a\cdot(b+c)=(a\cdot b)+(a\cdot c)$，$a+(b\cdot c)=(a+b)\cdot(a+c)$（**两个方向都要**） |
| H3 同一 | 存在 $0,1$：$a\cdot1=a$，$a+0=a$ |
| H4 互补 | $a+\bar a=1$，$a\cdot\bar a=0$ |

> 这四条是**公理化定义**；幂等、吸收、De Morgan 都能推出。前提：$B$ 至少两个元素。

## ★ 八之三、子代数 vs 子格（判断题必考）

| | 要求 |
| --- | --- |
| 子格 | 对 $\wedge$、$\vee$ 封闭 |
| 子代数 | 对 $\cdot$、$+$、$\bar{\ }$ **三种**都封闭，**且含 $0$ 和 $1$** |

设 $S=\{a,b,c\}$，$\mathcal{P}(S)$ 中：

- $S_1=\{\varnothing,\{a\},\{b,c\},\{a,b,c\}\}$ → **是子代数**（也必是子格）
- $S_2=\{\varnothing,\{a\},\{b\},\{a,b\},\{a,b,c\}\}$ → **是子格，不是子代数**（$\{a\}$ 的余元素 $\{b,c\}\notin S_2$）
- $S_3=\{\varnothing,\{a\}\}$ → **是子格，不是子代数**（$\{a\}$ 的余元素 $\{b,c\}\notin S_3$，且缺 $1$）

> **11/13 他自己造的例子**（同构于 $S_2$ 的链版）：$S=\{\varnothing,\{a\},\{a,b\},\{a,b,c\}\}$ 是一条链，对交并封闭 ⇒ 子格；但 $\{a\}$ 的余元素 $\{b,c\}\notin S$ ⇒ **不是子代数**。
> **链是造「子格非子代数」反例的万能模板**：链天生对 $\wedge,\vee$ 封闭，但余元素会把元素「翻到另一头」，几乎必然出界。

## 十、四张对比表

| 对比 | 左边 | 右边 |
| --- | --- | --- |
| 半群 vs 群 | 结合 | + 单位元 + 逆元 |
| 整区 vs 体 vs 域 | 交换 + $1$ + 无零因子 | 体：$1$ + 非零可逆；域：交换体 |
| 子群 vs 子格 vs 子代数 | 同一运算 + 群公理 | 子格：对 $\wedge,\vee$ 封闭；子代数：再对补运算封闭且含 0/1 |
| 同态 vs 同构 | 保运算 | 双射 + 保运算 |

## ★ 十一、10 条订正（错过的不能再错）

1. 对换是**奇**置换，恒等是**偶**置换。
2. $(a_1\cdots a_r)=(a_1a_r)\cdots(a_1a_2)$；反过来那条算的是逆。
3. $(1\,2\,3\,4)^4=I$，周期为 4。
4. 集合的交、并都封闭。
5. $n$ 元集合二元运算有 $n^{n^2}$ 种，不是 $2^{n^2}$。
6. 环 = 加法群 + **乘法半群**。
7. 「奇数环」不存在；偶数环是 $2\mathbb{Z}$。
8. 格要求**任意两个元素**有确界。
9. 奇偶乘法四种：偶偶得偶、偶奇得奇、奇偶得奇、奇奇得偶。
10. 非阿贝尔群上取逆是**反**自同构。
