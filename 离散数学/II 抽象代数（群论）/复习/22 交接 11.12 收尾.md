## 三、今天暴露的六个真缺口（按严重度排）

### 1. 亨廷顿公理默写不出来 ★★★

他说「只记得交换律、分配律、还有个逆」。实际四组：

| 公理 | 内容 |
| --- | --- |
| **H1 交换** | $a\cdot b=b\cdot a$，$a+b=b+a$ |
| **H2 分配** | $a\cdot(b+c)=(a\cdot b)+(a\cdot c)$ **和** $a+(b\cdot c)=(a+b)\cdot(a+c)$ |
| **H3 同一** | 有 $0,1$ 使 $a\cdot1=a$，$a+0=a$ |
| **H4 互补** | 有 $\bar a$ 使 $a\cdot\bar a=0$，$a+\bar a=1$ |

前提：**$B$ 至少含两个不同元素**。出处 PPT 7.5 P73。

**记错点**：把 H4 的「余元素 $\bar a$」叫成「逆」；H2 只记一个方向。

### 2. 子格 vs 子代数，包含方向记反 ★★★

他答：$S_2$ 是子代数不是子格，$S_3$ 都不是。**全反了。**

| | 子格？ | 子代数？ |
| --- | --- | --- |
| $S_1=\{\varnothing,\{a\},\{b,c\},\{a,b,c\}\}$ | ✅ | ✅ |
| $S_2=\{\varnothing,\{a\},\{b\},\{a,b\},\{a,b,c\}\}$ | **✅** | **❌** 缺余 |
| $S_3=\{\varnothing,\{a\}\}$ | **✅** | **❌** 缺余且缺 $1$ |

> [!warning] 一句话纠正
> **子代数更强。子代数一定是子格，子格不一定是子代数。**
> 子格：对 $\cap,\cup$ 封闭（2 个运算）
> 子代数：还要对补封闭 **且含 $0,1$**（3 个运算 + 两个特殊元）

### 3. $A_4$ 子群个数漏 $V_4$ ★★

他答 9，正确 **10**。按元数分类：$1+3+4+1+1=10$。

漏的是 **4 元子群 $V_4=\{I,(1\,2)(3\,4),(1\,3)(2\,4),(1\,4)(2\,3)\}$**（PPT 6.3 P89 专门讲过）。

### 4. 「$ab$ 与 $ba$ 同周期」以为要交换 ★★

他答「只有交换群才成立」。**错，恒成立。**

$$ba=a^{-1}(ab)a\quad\Longrightarrow\quad(ba)^k=a^{-1}(ab)^ka$$

所以 $(ba)^k=1\iff(ab)^k=1$。**共轭保周期，不需要交换。**

PPT 出处：**6.2 P117**（$(x^{-1}yx)^k=x^{-1}y^kx$）。

> [!warning] 「共轭」二字 PPT 全篇没有
> 我搜过 6.2/6.3/6.4/6.5/7 全部课件，**零命中**。
> 考场上写推导，不要写「共轭保周期」四个字。

**他主动联想到线性代数「相似保特征值」——这个链接是对的，可以保留。**
$P^{-1}AP$ 对应 $a^{-1}xa$，相似保特征值，共轭保周期。

### 5. 把「陪集个数」当成「子群个数」 ★★

随堂一 33：$n$ 元循环群，$k\mid n$，几个 $k$ 元循环子群？
他答 $n/k$，正确 **1 个**。

| 量 | 值 |
| --- | --- |
| 群元数 | $n$ |
| **子群元数** | $k$ |
| **陪集个数（指数）** | $n/k$ |
| **$k$ 元子群个数** | **1** |

**唯一性来源**：$H=\langle a^{n/k}\rangle$ 被 $n,k$ 完全确定。限定词是**「循环群」**——$S_3$ 非循环，2 元子群有 3 个。

### 6. 消去律消的是「公共因子」不是「结果」 ★

随堂一 23 答案对（0 个），但 gcd 和 lcm 的反例举反了。

$ax=ay\Rightarrow x=y$，**消的是左边那个 $a$**。
正确反例：$\gcd(5,2)=\gcd(5,3)=1\Rightarrow 2=3$。

## 五、今天最好的思考：横向链条最终版（5 组）

> [!important] 为什么单列一节
> 这是 11/12 唯一一件**不是我灌给他、而是他自己要出来的东西**。
> 他原话：「群的横向结构它不在链条上……一定要建立起非常多的联系才能理解得了的，太零散了。」
> 于是才有 5 组划分。**完整版在 [[21 横向结构全清单]] 第二节，这里只留骨架和接口。**

### 5.1　为什么要分组

纵向链条是「加条件升级」：半群 → 群 → 环 → 域。
横向不是升级，是**同一个群从 5 个高度看**。所以分组依据是「看的高度」，不是「难度」。

| 组 | 看的高度 | 回答什么问题 | 成员数 |
| --- | --- | --- | --- |
| **A** | 单个元素 | 这个元素多强？ | 4 |
| **B** | 整个群 | 这个群什么类型？ | 6 |
| **C** | 群里面 | 藏着什么小群？ | 6 |
| **D** | 把群切开 | 怎么切成一样大的块？ | 5 |
| **E** | 群到群 | 两个群怎么对应？ | 3 + 商群 |

**共 24 个概念。**

### 5.2　组内连线（每组自己怎么串）

| 组 | 内部结构 | 一句话 |
| --- | --- | --- |
| **A** | 四条互不干涉 | 都是单个元素的属性 |
| **B** | **两条线**：B1→B2→B3（交换性越来越强）；B4→B5→B6（置换筛选） | 循环 ⇒ Abel，但 Abel ⇏ 循环 |
| **C** | 从「最大」往「最特殊」筛 | 子群 → 平凡/真 → 三判据 → $\langle a\rangle$ → **正规** |
| **D** | **流水线**：合同关系 → 陪集 → 七性质 → 指数 → 代表系 → 拉格朗日 | 每步都靠前一步 |
| **E** | **往返**：同态 → 核 → 商群 → $G'\cong G/N$ → 自同构 | 一路「压」到底 |

### 5.3　组间 10 个接口（★ 这才是「零散」的病根）

> 概念分组只是摆放。**懂 = 知道组与组在哪里焊住。**

| # | 从 → 到 | 接口 | PPT |
| --- | --- | --- | --- |
| I1 | A1 周期 → C4 $\langle a\rangle$ | $\text{周期}(a)=\lvert\langle a\rangle\rvert$ | 6.3 **P41** |
| I2 | A4 生成元 → B3 循环群 | $G=\langle a\rangle$ | 6.3 P27 |
| I3 | B2 Abel → C5 正规 | **Abel 群的任意子群都正规** | 6.3 **P73** |
| I4 | C4 $\langle a\rangle$ → C1 子群 | $\langle a\rangle$ **一定**是子群 | 6.3 P26 |
| I5 | C1 子群 $H$ → D1 陪集 $aH$ | 用 $H$ 平移整个 $G$ | 6.3 P57 |
| I6 | D1 陪集 → C5 正规 | $H$ 正规 $\iff$ $\forall a:\ aH=Ha$ | 6.3 **P73** |
| I7 | C5 正规 $N$ → E3 商群 | **不正规就做不出商群** | 6.4 **P31** |
| I8 | E3 商群 → E2 核 | $\pi:a\mapsto aN$ 的核**恰好是** $N$ | 6.4 P31 |
| I9 | E1 同态 → C1/C5 | 子群的像仍是子群；**正规的像仍正规** | 6.4 P39, **P50** |

> - $A_n$ **必然**正规（指数 2）
> - 核**必然**正规（第一同态定理）
> - 商群**必须**用正规子群（否则乘法不封闭）
>
> 其余 7 个都是「定义直接推」。

### 5.4　12 级脊柱（全部压成一条线）

```
① 元素 a
     │ 反复自乘，看何时回到 1
② a 的周期 n ══════ |⟨a⟩|          【A1 / 6.3 P31,P41】← I1
     │ 生成

     │ 去掉「循环」这个限制

     │ 拿 H 平移整个群

     │ 数一数有几块

⑦ 正规子群 N ── aN=Na              【C5 / P73】← I6

⑪ 同构 G′ ≅ G/N ── 第三同态定理     【6.4 P36】
     │ 当 G′ = G
⑫ 自同构 ── 保周期、元数、子群结构   【6.4 P20】
```
